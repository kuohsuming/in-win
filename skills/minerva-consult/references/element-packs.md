# 領域元素包(Element Packs)

Phase 1 用完「通用元素清單」後,依請求類型讀對應的一節,把該領域的**額外必問元素**也加進缺口表。
每個元素附「為何影響決策品質」與「缺了就這樣問(要逼出具體)」。原則不變:抽象詞一律追問到有數字/日期/範例/名字。

## A. 內容 / 寫作
(信件、貼文、文案、報告、講稿…)

- **讀者的起點與立場** — 讀者現在知道什麼、相信什麼、對這件事的態度是正/負/中立?
  *不知道起點就抓不到該補的落差與該化解的抗拒。* 缺 → 「讀這個之前,他們已經知道多少?會不會有抵觸?」
- **你要他讀完後做的一個動作** — 回信?點連結?改變看法?批准?
  *沒有目標動作,文章就沒有焦點。* 缺 → 「讀完你最希望他做哪一件事?」
- **語氣 / 品牌聲音** — 正式或口語?親切或權威?
  缺 → 「能給一篇你覺得語氣對的範例嗎?」
- **通路與長度** — email / 站內 / 社群 / 口頭?字數或時間上限?
  缺 → 「發在哪、大概多長?」
- **不能說 / 敏感點** — 有沒有法務、公關、或絕不能提的東西?
  *一句踩雷可能毀掉整篇。* 缺 → 「有什麼是絕對不能寫進去的?」

## B. 產品 / 功能 / 規格

- **要解決的使用者問題與情境** — 誰、在什麼情況下、卡在哪?
  *需求若從「解法」出發而非「問題」,常做出沒人用的東西。* 缺 → 「使用者上一次遇到這個痛點,是什麼情境?」
- **成功指標** — 上線後看哪個數字判斷有效(採用率、留存、轉換…)?
  缺 → 「怎樣的數字變化會讓你說這功能成功?」
- **範圍 / MVP 邊界** — 這一版一定要有 vs 之後再說?
  缺 → 「如果只能做一個核心,是哪個?」
- **限制** — 平台、既有系統、法規/隱私、上線時間。
- **邊界與失敗情境** — 極端輸入、離線、權限、濫用會怎樣?
  *邊界情況常是災難來源。* 缺 → 「最異常的使用者會怎麼用/濫用它?」
- **相依與交接** — 需要誰配合(設計/後端/法務)?誰做決定?

## C. 技術 / 系統設計

- **規模與流量** — 資料量、QPS、使用者數、成長曲線?
  *規模決定整個架構;為 100 人和為 1 億人設計是兩件事。* 缺 → 「尖峰大概多少量?一年後呢?」
- **關鍵非功能需求(取捨)** — 延遲、可用性、一致性、成本,哪個優先?
  *這些彼此衝突,不排序就無法選型。* 缺 → 「延遲、可用性、成本,哪個最不能妥協?」
- **既有環境與限制** — 現用技術棧、雲、團隊技能、不能動的舊系統?
- **資料特性** — 讀寫比、結構化程度、保存期、隱私分級?
- **失敗模式與復原** — 某環節掛掉會怎樣?可接受的資料遺失/停機是多少?
  缺 → 「哪個元件掛掉最痛?能容忍多久停機?」
- **安全與合規邊界** — 誰能存取什麼?有無法規要求?

## D. 商業 / 策略決策

- **決策的可逆性與時限** — 這是可回頭的實驗,還是一次性大賭注?何時必須拍板?
  *可逆的決定該快、不可逆的該慢而謹慎。* 缺 → 「選錯的話,回頭的代價多大?」
- **選項全集** — 檯面上有哪些方案?「什麼都不做」算不算一個?
  *常見盲點是只在兩個選項間糾結,漏掉更好的第三條路。* 缺 → 「除了這兩個,還有哪些可能?維持現狀會怎樣?」
- **判準與權重** — 用哪些標準比較選項?各佔多重?
- **資源與槓桿** — 有多少錢/人/時間?你能施力的關鍵點在哪?
- **利害關係人與阻力** — 誰要買單、誰會反對、誰有否決權?
- **假設與數據** — 這個決定押在哪些假設上?哪些有數據、哪些是猜?
  缺 → 「這方案要成立,必須為真的關鍵假設是什麼?你怎麼知道它成立?」

## E. 研究 / 分析

- **要回答的具體問題** — 是描述現況、比較、找因果、還是預測?
  *問題類型決定方法;因果和相關不能混。* 缺 → 「你要的是『是什麼』還是『為什麼』?」
- **決策用途** — 這個分析要支持哪個即將做的決定?
  *不接決策的分析容易做成沒人用的報告。* 缺 → 「拿到結論後,你接下來要決定什麼?」
- **資料來源與品質** — 有什麼資料?可信度、涵蓋範圍、偏誤?
- **判斷門檻** — 結果要到什麼程度你才會採信/行動?
  缺 → 「差異要多大、信心要多高,你才會據此行動?」
- **反例與否證** — 什麼結果會推翻你目前的假設?
  *只找支持證據是最大的偏誤來源。* 缺 → 「什麼發現會讓你說『我原本想錯了』?」

## F. 個人 / 生活決策

- **真正在意的價值** — 這個決定底層你最想守住什麼(自由、安全、關係、成長…)?
  *表面選項之爭,底下常是價值排序之爭。* 缺 → 「如果撇開細節,你最不想犧牲的是什麼?」
- **時間框架** — 你在為多久之後的自己做決定?
- **可逆性與最壞情況** — 選錯能不能回頭?最壞你承受得住嗎?
- **被忽略的選項** — 是不是被框在「A 或 B」,漏了折衷或第三條路?
- **情緒 vs 資訊** — 現在的急迫感是真的期限,還是情緒?哪些是事實、哪些是擔憂?
  缺(且合適時,以支持態度)→ 「這個急,是有硬性期限,還是心裡的壓力?」

> 注意:個人決策是提供思考架構與資訊、幫對方自己想清楚,不是替他做決定或給出斷言式建議。
