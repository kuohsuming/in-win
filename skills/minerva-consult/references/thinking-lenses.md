# 思考鏡頭(Thinking Lenses)

可重複調用的分析框架。**不是每個階段都套**,而是在需要某種特定思考時,像換鏡頭一樣調用。
產出一律為**提議**、走五段式可決策說明、交人核可(同全 skill 的把關鐵律)。

---

## 藍海四動作(Eliminate / Reduce / Raise / Create)—— 取捨與差異化鏡頭

一台結構化的取捨引擎,兩兩對稱,**強迫同時想減法與加法**(人和 AI 天生偏向只做加法,這是解藥)。

- **消去 Eliminate** — 哪些是產業視為理所當然、但其實不必要、顧客不在乎的?→ 不做。
- **減少 Reduce** — 哪些過度投入、可以降到「夠用」就好?→ 省下資源。
- **提升 Raise** — 哪些不足、顧客其實很在意?→ 做得更好。
- **創造 Create** — 哪些整個領域都沒提供、但會帶來新價值?→ 開新局。
- (未被四動作碰到的 = **保留**,隱含的預設。)

**兩個調用場合:**

1. **improve 模式的改善方向**(Phase 0.5 第 3 步)
   對既有產物逐項套四動作,給「往哪改」的系統性方向——不只挑毛病修補,而是**天然逼出減法**(消去/減少),避免 AI 只會加東西。

2. **對標之後的學習/差異化**(Phase 2.7 之後,原生用途)
   對競品/商業模式套四動作:消去產業陋習、減少過度競爭處、提升顧客在乎處、創造全新價值。
   **目標是差異化,不是超越**——單純「學競品優點」只會變成競品的更好版本(紅海裡卷);四動作用「消去/減少」拉開距離、騰出資源,用「提升/創造」在別的維度贏。

**紀律(必守):**
- 四動作產出皆為**提議**,逐條走五段式;尤其「**消去/減少**」須附「**顧客不在乎/過度**的證據」——不許憑感覺砍,砍掉的可能是某群人的命根子。
- 「**創造**」須接回真實 `pain_point` 與 Phase 2.7 的對標證據,**不為新而新**(防止淪為「創造全新品類」的空想)。
- 標 `origin`:哪些基於實據、哪些是 AI 判斷。

### 搭配:策略布局圖(Strategy Canvas)
四動作的最佳搭檔。橫軸=競爭因素、縱軸=投入高低,把「你 vs 競品」的曲線畫出來,一眼看出**大家都擠在哪、你的曲線該長成什麼不一樣的形狀**。
與既有的對標矩陣、視覺化能力天然契合;多方案或差異化定位時特別有用,單純比價時不必畫。

## 探針式 strawman —— 突破隱性知識的引出鏡頭

**前提:光靠問有天花板。** 人「知道的比說得出來的多」(Polanyi 隱性知識)——有些需求問不出來,但看到具體東西就會反應。所以除了問,要**給人一個靶去打**。

- **探針(probe),不是初稿(draft)**:目的不是給對的答案,而是**用故意留洞的具體方案,把問答勾不出來的邊界釣出來**。被打臉即成功;心態與求穩相反,大膽猜。內部標記「這是探針,不是推薦」定錨 AI 心態。
- **主動節奏**:反問約 2–3 輪後主動穿插拋靶,不是等撞牆才救援。依據是「該換檔了嗎」(問答變短變淺=能量在降),趁人還沒灰心就換。問答(向內、累)與打靶(向外、輕鬆)交替如呼吸。
- **單靶 vs 雙靶**:方向清楚 → 單靶挖細節;**方向模糊 → 雙靶**(兩個相反極端 A 極簡/B 極繁),讓人在光譜上標位置而非批評單點,對抗錨定、一次勾出「方向偏好 + 例外底線」。雙靶特別適合當「換檔」的第一拋。
- **核心強制動作:批評 → 邊界。** 每句批評即時翻譯成一條邊界/需求/取捨,回填活文件。批評 = 新邊界的線索,別只改方案而漏了萃取。

**與其他機制的關係**:improve 模式 = 使用者自己帶靶來;strawman = build 模式下 AI 主動造靶。兩者共用「批評→邊界」的萃取,產出皆走提議→核可、回填活文件。
