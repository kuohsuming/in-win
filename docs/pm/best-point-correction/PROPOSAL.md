# 提案：判定前先做「最佳點修正」

> 表面平整檢查的 pass/fail 判定公式調整。判定前先在整片所有有效量測點中找出**最佳點**（讀值絕對值最靠近 0 者），以最佳點的讀值為基準，把每一點修正為「相對最佳點」的值，再拿修正值比對該點的上下限。合格條件由「下限 ≤ 讀值 ≤ 上限」改為「下限 ≤ 修正值 ≤ 上限」。
> 對應需求：需求規格書 3.3 JDG-01（修訂）、新增 JDG-07；上下限設定（JDG-06）不變。
> 狀態：rev 1（2026-11-17 簽核，方案 A：顯示原始讀值、判定用修正值；DB 不加欄位）。簽核紀錄：👔🔬💻 solo PO 簽核 approve @ 2026-11-17。

---

## 1. 背景與目標

目前每個量測點各自拿**原始讀值**比對上下限（JDG-01）。問題：整片板子若有共同的擺放／基準偏移（例如治具沒完全貼合、整片略為墊高或墊低），每一點的讀值都帶著這個共同偏移，明明平整度沒問題卻可能整片判不合格。

PO 要求改成**以整片最平的點為基準**來判平整度：先找出整片中最靠近標準（0）的那一點當基準，把它歸零，其他點看相對這個基準的偏差，再判上下限。這樣判的是「這片相對它自己最佳點的平整度」，而不是「相對絕對標準的位置」。

## 2. PO 決定（2026-11-17）

| 題目 | 決定 |
| --- | --- |
| 最佳點定義 | 整片所有有效量測點中，**讀值絕對值最小**（最靠近 0）的那一點 |
| 最佳點距離 | 最佳點的讀值本身，含正負號（最佳點 −3 → 距離 −3；+2 → +2） |
| 修正公式 | **修正值 ＝ 探測值 − 最佳點讀值**（方案 B：把最佳點歸零；PO 2026-11-17 於提問中確認採減號） |
| 判定 | 修正值 > 上限 或 < 下限 → 不合格；落在上下限內 → 合格 |

PO 原話：「找出最佳點（最靠近 0 的點），取最佳點的距離⋯以最佳點的距離對每一個探測點進行修正⋯當修正值落於該點的上下限以外就是失敗，其他就是過關」；正負號經提問確認為方案 B（探測值 − 最佳點值）。

## 3. 設計

### 3.1 判定流程（新增一個板級前置步驟）

目前：逐點獨立 `judge(讀值, 上下限)`。
改為，每量一片：

1. **蒐集有效點**：整片所有「使用中」且讀值有效的量測點（排除設備異常、未校準、無數據、拿不到 IP、維修中、未啟用的點——這些本來就不參與合格判定）。
2. **找最佳點**：有效點中 `|讀值|` 最小者；其讀值記為 `best`（含正負號）。
3. **逐點修正**：每個有效點 `修正值 = 讀值 − best`。最佳點本身修正後為 0。
4. **逐點判定**：`下限 ≤ 修正值 ≤ 上限` → 合格；`修正值 > 上限` → 偏高；`修正值 < 下限` → 偏低（沿用 JDG-01 的三態，只是比的對象由讀值換成修正值）。
5. **整片判定**：沿用 JDG-02／JDG-04 不變（任一點異常→設備異常；任一點偏高或偏低→不合格；全部合格→合格）。

### 3.2 邊界情形

- **全部點都是設備異常**：沒有有效點、無最佳點 → 整片為設備異常（JDG-04），不需要修正。
- **只有一個有效點**：它即最佳點，修正值 = 0；若該點上下限含 0（預設 ±0.2 含 0）則合格；若上下限同側不含 0 則依規則判（與現行一致）。
- **並列（兩點 `|讀值|` 相同，例如 +2 與 −2）**：取**讀值較小（較負）者**為最佳點，確保結果可重現。浮點讀值完全並列極罕見；此規則只為決定性，列為可調的次要決定。

### 3.3 顯示、紀錄、3D、匯出（★需 PO 於簽核時確認）

本案 PO 只明確說「pass/fail 公式修正」。判定改用修正值後，畫面與紀錄顯示哪個值有兩種做法，**建議方案 A**：

| 面向 | 方案 A（建議：判定用修正值，顯示維持原始讀值） | 方案 B（畫面全改顯示修正值） |
| --- | --- | --- |
| 主畫面每點方塊 | 主顯示**原始讀值**（探頭真實讀值，作業員按壓時所見一致）；不合格點的「超出上限／低於下限」註記改用**修正值**計算 | 顯示修正值（相對最佳點），看不到探頭真實讀值 |
| 量測紀錄 | 存原始讀值（`measured_value` 不變）＋**本片最佳點讀值 `best_offset`**（僅本機暫存 JSON，供回溯；DB 不加欄位，App 帳號無 DDL 權限，且可由各點 `measured_value` 推回）；標準值 0、上下限不變 | 存修正值為 `measured_value`，原始讀值另存 |
| 3D 繪圖 | 維持原始讀值（P3D 本來就不判定，P3D-A2；「扣除傾斜」模式另有殘差檢視） | 改顯示修正值 |
| Excel 匯出（EXP-03） | 12 點維持原始讀值；可另加最佳點修正量欄（次要，可不加） | 改匯出修正值 |

**建議方案 A**：理由——(1) PO 要求的是「判定公式」改，不是改讀數顯示；(2) 作業員逐一按壓探頭對位時，方塊顯示的應是探頭真實讀值，否則對不上；(3) 原始讀值完整保留，修正量可回溯，稽核完整；(4) 3D 的「扣除傾斜」已提供另一種相對檢視，不宜再動。**此欄請你簽核時確認 A 或 B。**

### 3.4 升級與相容

- 無資料庫結構變更（`best_offset` 只寫本機暫存 JSON，不進 DB；可由各點 `measured_value` 推回）。
- 判定邏輯改變：**同一片板子、同一組讀值，判定結果可能與舊版不同**（舊版比絕對讀值，新版比相對最佳點）。升級說明須提醒品保：整片共同偏移不再造成整片不合格，但相對最佳點的偏差變嚴。
- 上下限設定（JDG-06）、整片判定（JDG-02／04）、校準、設備判定全部不變。

## 5. 驗收

| 編號 | 情境 | 預期 |
| --- | --- | --- |
| AC-1 | 三點讀值 +2.0、−3.0、+2.5，各點上下限 ±0.2 | 最佳點 +2.0（`|2|` 最小）；修正值 0、−5.0、+0.5 → 第 1 點合格、第 2 點偏低、第 3 點偏高 → 整片不合格 |
| AC-2 | 整片共同墊高：所有點 +5.0〜+5.3，上下限 ±0.2 | 最佳點 +5.0；修正值 0〜+0.3 → +0.3 的點偏高，其餘合格（舊版會整片偏高） |
| AC-3 | 最佳點本身 | 修正後為 0；上下限含 0 時必合格 |
| AC-4 | 一點設備異常、其餘有效 | 異常點不參與最佳點計算，整片為設備異常（JDG-04） |
| AC-5 | 只有一個有效點 | 該點即最佳點、修正 0、依其上下限判 |
| AC-6 | 並列 +2.0 與 −2.0 | 取 −2.0 為最佳點（較小者），結果可重現 |
| AC-7（方案 A） | 不合格點的畫面 | 方塊主顯示原始讀值；註記「超出上限 x／低於下限 x」以修正值計算；紀錄存原始讀值＋最佳點修正量 |

## 6. 實作順序

1. M1 判定核心：`measure.best_offset`／修正、兩階段判定、`judge` 比修正值。
2. M2 主畫面：蒐集有效讀值求最佳點、逐點修正判定、不合格註記用修正值、方塊顯示依方案。
3. M3 紀錄／匯出／3D 依選定方案調整（方案 A：加 `best_offset`、其餘不動）。
4. M4 文件、截圖、變更紀錄。
5. M5 真機確認（mosa）。

## 7. 風險

| 風險 | 處理 |
| --- | --- |
| 判定結果與舊版不同，品保依舊基準看會誤解 | 升級說明清楚說明「改為相對最佳點判平整度」；變更紀錄標明 |
| 最佳點本身是離群假性低點（例如某點故障讀出接近 0 的假值）會把整片基準帶偏 | 只有「有效」讀值參與；設備異常／未校準點已排除；校準正常的前提下假性 0 風險低。必要時另立「最佳點離群保護」決定 |
| 顯示值與判定值不一致造成作業員混淆（方案 A） | 不合格註記以修正值說明差距；操作說明書補充「判定以相對最佳點的修正值」 |
| 並列 tie-break 影響結果 | 規則固定（取較小讀值）、可重現；列為可調次要決定 |
