## 1. 背景與目標

主畫面以每個探頭各自的允許誤差判定合格與否。作業員只看得到每點的數字，看不出整片表面哪裡凸、哪裡凹、整體是什麼形狀。

本模組要做到：

1. **依實際設定與實際讀值繪圖**：探頭數量、排數取自「設備設定」中目前的 DL-EN1 使用中設備，數值取自這一片的讀值；不假設固定 3 排 × 4 點。
2. 有效量測點少於 3 點，或全部在同一直線上（例如只有 1 排）時，按下即以警告訊息拒絕，不畫圖、不推估。
3. 預設顯示「相對標準件」的高低：數值與主畫面相同（mm、小數 3 位）。可切換「扣除傾斜」，看扣除整片傾斜與高低後的形狀與平面度。
4. 板子每 0.7 秒旋轉 30°，12 個角度循環。
5. 不誤導：高度放大以允許誤差為基準，好板看起來是平的；探頭範圍以外的形狀淡化並註明為推估。
6. 在產線 IPC（DRP-A100，Atom x6425E）上按下後 0.3 秒內出現第一張圖。

## 4. 輸入資料

### 4.1 板子尺寸（主畫面設定，P3D-10）

- 主畫面頂端工具列在「取出測試數據」與設備設定（鉛筆）之間新增按鍵，文字顯示目前尺寸，例「板子 1000×600×5 mm」。
- 按下在主畫面中央開啟小視窗（嵌入遮罩，UI-09）：

  | 欄位 | 範圍 | 預設 |
  | --- | --- | --- |
  | 長 mm（x，作業員看過去的左右） | 1～5000，小數 1 位 | 1000 |
  | 寬 mm（y，前到後） | 1～5000，小數 1 位 | 600 |
  | 高 mm（實際板厚） | 0.1～100，小數 1 位 | 5 |

  超出範圍或非數字時欄位標紅、下方說明、「儲存」停用。按鍵「取消」「儲存」。
- 儲存後立即生效，存於本機 `QSettings("flatness", "flatness")` 的 `plate/length`、`plate/width`、`plate/height`（與取出測試數據記住的資料夾同一處），App 重新啟動後保留。讀到不合法的值時使用預設並記入日誌。
- 不需密碼：只影響 3D 繪圖，不影響判定與資料庫。等待、讀取中、偵測設備中停用（同其他工具列按鍵）。
- 高（板厚）標示在圖上（6.5）；圖上的厚度為示意（`Tv = 0.05 × 長`），不按比例，否則 5 mm 的板在 1000 mm 長的圖上看不見。
- 探頭固定在板子下方（PO 確認），不提供設定。

### 4.2 探頭位置與名稱（P3D-05）

位置與名稱全部取自「設備設定」，不另外設定：

- **前後（y）由「第幾排」決定**：DL-EN1 的位置為第 `n` 排，`R` 為使用中與維修中設備最大的排號：`y = width × (n − 0.5) / R`。排號照實際位置，例如第 1、3 排使用中、第 2 排維修中，第 2 排的位置空著（維修中的探頭不畫）。
- **左右（x）由探頭 ID 決定**：該台探頭數量 `N`，探頭 ID `id`（1～N，設備設定自動編號）：`x = length × (id − 0.5) / N`。
- **名稱**：每個探頭在圖上以「排名稱 位置名稱」標示（設備設定的 `name` 與探頭 `description`），例「中排 右中」；資訊欄與拒絕訊息也用同一名稱。
- 例：mosa 目前第 1 排 1 台、2 個探頭（左、右）→「前排 左」(250, 300)、「前排 右」(750, 300)，兩點在同一直線上，按下即拒絕（P3D-03）。第 1～3 排各 4 個 → 「前排 左」(125, 100)、「後排 右」(875, 500)。

### 4.3 讀值（快照）

按下「3D 繪圖」時，取主畫面目前這一片的結果做成快照。之後主畫面重新偵測或更新，都不影響已開啟的視窗。

```python
@dataclass(frozen=True)
class ProbeReading:
    key: str                 # 識別：「排號-探頭 ID」，例「2-3」（內部用，不顯示）
    name: str                # 顯示名稱：排名稱 + 位置名稱，例「中排 右中」
    x: float                 # mm（4.2）
    y: float                 # mm
    value_mm: float | None   # 主畫面的讀值（已對標準件歸零，CAL-03）；None = 無數據（設備異常、未校準等）
    tolerance_mm: float      # 該探頭的允許誤差（JDG-06）
    state: str               # "ok" | "hi" | "lo" | "err"，沿用主畫面的單點判定
```

## 5. 計算

全部在 `plate3d/model.py`，純 Python，不依賴 Qt。

1. **有效點**：`value_mm` 不是 None 的點。少於 3 點 → 拒絕（P3D-02）：
   > 無法繪製 3D：本次只有 N 個有效量測點，至少需要 3 個。
   > （設定 M 個探頭；無數據：中排 右、後排 左）

   設定的探頭本來就少於 3 個時，第二行改為「（目前設定只有 M 個探頭）」。
2. **同一直線**：有效點在任一方向的分佈寬度小於 1 mm 時拒絕（P3D-03）。判斷方式是取點座標的共變異矩陣，較小特徵值開根號小於 1 mm 即為同一直線。
   > 無法繪製 3D：所有有效量測點在同一直線上（例如只有 1 排），至少需要 2 排探頭。
3. **高度方向**：探頭在板子下方，`h = −value_mm`（mm）。
   理由：探頭在下方往上頂時，表面越低，探頭被壓越多，讀值越大。標籤上的數值仍為讀值本身，與主畫面一致（7.2）。
4. **兩種顯示模式**（單位皆為 mm）：
   - **相對標準件（預設）**：`z_k = h_k`。0 即標準件的高度。
   - **扣除傾斜**：最小平方解 `h = a + b·X + c·Y`（`X = x/1000`、`Y = y/1000`），`z_k = h_k − (a + b·X_k + c·Y_k)`。
     平面度 `flatness = max(z) − min(z)`，稱為「平面度（最小平方）」，只供檢視，不是 ISO 1101 最小區域法，也不用於判定。
5. **插值網格**：薄板樣條，與原型 `tps()` 相同：解 (n+3)×(n+3) 線性方程，部分選主元高斯消去。座標用 `(x/length, y/length)`。
   - 網格 `nx = 41`，`ny = max(9, round(40 × width / length) + 1)`。
   - 插值只用來畫點與點之間的形狀，不得用於判定。
   - 每個網格點記下是否在有效點的**凸包**內（含邊上），供 6.4 淡化用。
6. **顯示比例**（防止好板被放大成凹凸不平）：
   - `lim = max(max(有效點的 tolerance_mm), max|網格值|, max|z_k|)`
   - 示意板厚 `Tv = 0.05 × length`
   - 高度倍率 `ex = 0.4 × Tv / lim`。允許誤差的高度在畫面上固定為示意板厚的 40%；在允許誤差內的板子不會被畫得比這更凹凸。
   - 畫面標示「高度放大約 ×N 倍」，`N = round(ex)`。

回傳：

```python
@dataclass
class SurfaceModel:
    points: list[ProbeReading]          # 全部探頭（含無數據）
    mode: str                           # "standard" | "detrended"
    z_mm: dict[str, float]              # label → 顯示高度；無數據的點不在內
    grid: list[list[float]]             # [ny][nx]，mm
    inside: list[list[bool]]            # [ny][nx]，是否在有效點凸包內
    highest: tuple[str, float]          # (label, z)
    lowest: tuple[str, float]
    spread_mm: float                    # 最高 − 最低（standard：讀值差；detrended：平面度）
    lim_mm: float
    thickness_vis: float                # Tv
    exaggeration: float                 # ex
    plate: PlateConfig                  # 長、寬、高

class RefuseError(Exception):           # 第 1、2 步拒絕，訊息即警告文字
    ...

def build_model(readings, plate, mode="standard") -> SurfaceModel: ...
```

兩種模式在開啟時各算一次並保存，切換時不重算。

## 6. 繪圖演算法

全部在 `plate3d/renderer.py`，無狀態：輸入 `SurfaceModel`、旋轉角、畫布大小與色票，用 `QPainter` 畫。6.1～6.3、6.5 與原型 `draw3d()` 相同（以下只列重點與修改處）。

### 6.1 座標與視角

- 世界座標：x 向右（板長）、y 向後（板寬）、z 向上，原點為左前角。
- 仰角 `el = 15°`；方位 `az = −45° + rot`，`rot` 為 0、30、60…330。
- `v = (cos el·cos az, cos el·sin az, sin el)`、`rt = (−sin az, cos az, 0)`、`up = (−sin el·cos az, −sin el·sin az, cos el)`。

### 6.2 投影（正交）

```
X = x − L/2,  Y = y − W/2,  Z = z + Tv/2
sx    = cw/2 + sc·(X·rt.x + Y·rt.y)
sy    = ch/2 − sc·(X·up.x + Y·up.y + Z·up.z)
depth = X·v.x + Y·v.y + Z·v.z
D = √(L² + W²),  hmax = 0.4·Tv
sc = min(cw·0.92 / D, ch·0.84 / (D·sin el + (Tv + 2·hmax)·cos el))
```

上表面網格點 `z = grid[j][i] × ex`。`sc` 與旋轉角無關，旋轉時板子大小不變。

### 6.3 多邊形

上表面每格一個四邊形；四個側面只畫面向眼睛的（`n.x·v.x + n.y·v.y > 1e−6`），上緣跟著表面、下緣為上緣 − Tv，深度減 0.001。依平均深度由小到大排序填色（畫家演算法），同色填滿並以同色 0.7px 描邊，開啟反鋸齒。

### 6.4 上表面明暗與推估區淡化

- 明暗同原型：`SHADE = {lo: 140, hi: 228, relief: 6, light: (−0.55, 0.75, 0.6)}`；底色 `t = (z̄ / lim + 1) / 2`，`base = lo + (hi − lo)·clamp(t, 0, 1)`；光源跟著眼睛；`k = clamp(1 + 1.8·(n·LW − LW.z), 0.5, 1.14)`；`gray = min(255, round(base × k))`。
- **新增**：四角都不在凸包內的格子，灰階往中間值 184 拉近 60%（`gray = 184 + 0.4 × (gray − 184)`），表示這一區是推估的。

### 6.5 側面、輪廓、尺寸

同原型：側面 `s = 0.45 + 0.35·min(1, (n·v_xy)/cos el)`；輪廓 1.1px 黑色 75%；尺寸文字「長 1000 mm」「寬 600 mm」13px `ink`（數值取自板子尺寸設定）。另在繪圖區左下角標「板厚 5 mm（示意，不按比例）」。

### 6.6 量測點與標籤

- 點位置：有數據的點 `z = z_k × ex`；無數據的點 `z = 0`。
- 有數據：橘色 #FF7A00 實心圓，半徑 4.5px，1.2px 黑框。無數據：紅色（`ng`）✕，臂長 6px，線寬 3px。
- 標籤兩行置中：
  - 第一行：探頭名稱「排名稱 位置名稱」，例「中排 右中」（文字字型 13px 粗體）。
  - 第二行：相對標準件模式寫**讀值**（與主畫面相同，帶正負號、小數 3 位，例「+0.217」）；扣除傾斜模式寫殘差（例「+0.040」）；無數據寫「無數據」。
  - 數字字型 13px 粗體；框寬為兩行較寬者 + 10px，高 34px，圓角 4px。
  - 一般為白底 90%、文字 #1C2326；超出允收（`hi`／`lo`）或無數據為紅底 rgba(200,50,43,.94)、白字。
- 避讓：依深度由近到遠放置，依序試上、下、左、右、更上、更下六個位置，取第一個不重疊（含 2px 間距）者，全部重疊時用第 1 個。引線 1px 黑色 55%。
- 所有多邊形與輪廓畫完後，再依深度由遠到近畫點與標籤。

### 6.7 快取

同一模式、同一畫布大小下，每個角度第一次畫完即存成 `QPixmap`，之後播放直接貼圖。切換模式或改變視窗大小時清除快取。

### 7.3 行為

- 開啟時：建立快照與兩種模型、模式為「相對標準件」、旋轉角歸零、自動播放。
- 播放：`QTimer` 每 700ms，`rot = (rot + 30) % 360`。
- 「◀ 30°」「30° ▶」：先暫停再轉 ∓30°。
- 鍵盤：← → 轉動，空白鍵播放／暫停，M 切換模式，Esc 關閉。
- 關閉時停止計時器、釋放快取。

## 11. 測試與驗收

**單元測試**

1. `vectors.json`（扣除傾斜模式，原單位 µm，比對時換成 mm）：
   - `fail_below`：平面度 66.433 µm。
   - `fail_above`：與 `fail_below` 正負相反，平面度相同。
   - `missing_one`：第 2 點為 None，平面度 66.591 µm。
   - `pure_tilt`：殘差全為 0。

   誤差 < 0.01 µm。已以純 Python 實作驗證這四組數字。
2. 相對標準件模式：`z_k` 等於 `h_k`；`spread_mm` 等於讀值最大減最小。
3. 拒絕：0、1、2 個有效點 → `RefuseError`，訊息含有效點數與無數據的點名；1 排 4 點、2 排但每排只有同一 x 的點（共線）→ 同一直線訊息；3 點且不共線 → 可畫。
4. 板子尺寸：預設 1000×600×5；0、負數、超過上限、非數字不可儲存；儲存後重新讀取相同；QSettings 內為不合法值時用預設。
   預設位置：1 台 2 探頭 → (250, 300)、(750, 300)；3 台 × 4 → 前排左 (125, 100)、後排右 (875, 500)；第 1、3 排使用中、第 2 排維修中 → y 為 100、500（第 2 排位置空著）；標籤文字為「排名稱 位置名稱」。
5. 插值網格在每個量測點的值與 `z_k` 相差 < 1e−6 mm；凸包外的格子 `inside` 為 False。
6. 比例：讀值全在 ±0.01 mm、允許誤差 0.2 mm → `lim = 0.2`（好板畫面上近乎平坦）。
7. 繪製：12 個角度、兩種模式皆可畫到離屏 `QImage`；標籤框兩兩不重疊；第二圈使用快取。

**畫面驗收**

- 板子有厚度，可見兩個側面，側面上緣隨表面起伏；凸處白、凹處灰；量測點範圍外顏色較淡。
- 旋轉時板子大小不變，每 0.7 秒轉 30°。
- 預設模式下，標籤數值與主畫面同一點完全相同。
- 超出允收的點標籤為紅底，無數據為紅 ✕。
- 視窗在全螢幕主畫面中央，不會跑到後面；Esc 可關閉。
- mosa 目前設定（1 台 2 探頭）按下 → 立即出現拒絕訊息。

**現場驗收**

- 在 DRP-A100 量測第 10 節的時間並記錄。
- 用墊片在某點墊高，確認圖上凹凸位置與方向正確（探頭在下方：讀值變大處應顯示為凹陷）。
