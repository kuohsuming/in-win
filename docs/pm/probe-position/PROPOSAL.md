# 提案：探頭位置改為每個探頭設定第幾排、第幾點

> 表面平整檢查系統的設定與畫面調整。探頭在板子下方的位置，由工程人員在「設備設定」逐一設定「第幾排」「第幾點」，不再由所屬 DL-EN1 的位置與探頭順序推定。
> 對應需求：需求規格書 3.13 探頭位置（POS-01～POS-09，**待確認**）。全部條文簽核前不實作。

## 1. 背景與目標

目前每台 DL-EN1 設定一個位置「第 N 排」（`key` = `row-1`～`row-10`），這台的探頭依 ID 順序由左到右，就當作探頭在板子上的位置。實際安裝時，同一台 DL-EN1 的探頭可能分散在板子不同的排，一排也可能混了不同台的探頭（GT2 放大器串在 DIN 軌上，但感測頭以線材接出，裝在哪裡不受串接順序限制）。這時主畫面與 3D 圖上的位置都會和實物不符。

本提案要做到：

1. 每個探頭各自設定「第幾排」「第幾點」（未定、1～5），預設未定。
2. 量測主畫面依探頭的實際位置排列，作業員看到的排與點就是板子上的排與點。
3. 3D 繪圖依同一位置畫在板子上。
4. 排與點都有名稱（預設「排1」～「排5」、「點1」～「點5」），可修改。
5. 量測紀錄、允收標準、校準、BOOTP 完全不受影響，舊資料照常對應。

## 5. 設計

### 5.1 資料

**探頭物件**（`lan_device.dl_en1_config.probes[]`、定義檔 3.7.1）新增兩個選填欄位：

```json
{ "id": 2, "description": "點2", "row": 1, "point": 2, "tolerance": 0.5 }
```

- `row`、`point`：整數 1～5，兩者同時存在或同時省略；省略即未定。
- 存在 JSON 欄位裡，`lan_device` 資料表結構不需要改。
- 升級：既有探頭沒有這兩欄，即為未定，不做自動轉換（POS-A1：不猜位置）。
- JSON Schema（`app/flatness/dl-en1.schema.json`）的 `probe` 加入：

```json
"row":   { "type": "integer", "minimum": 1, "maximum": 5 },
"point": { "type": "integer", "minimum": 1, "maximum": 5 }
```

並在 `dependentRequired` 加上 `"row": ["point"], "point": ["row"]`。

- 跨設備驗證（`bootp.validate`，Schema 表達不了的部分）：使用中與維修中所有探頭的 `(row, point)` 不可重複。

**排名稱、點名稱**：新資料表（`sql/in-win.sql`，可重複執行）。

```sql
CREATE TABLE IF NOT EXISTS flatness.plate_position_name (
  kind        ENUM('row','point') NOT NULL COMMENT '排／點（POS-03）',
  seq         TINYINT UNSIGNED    NOT NULL COMMENT '第幾排／第幾點（1～5）',
  name        VARCHAR(10)         NOT NULL COMMENT '名稱；預設 排1～排5、點1～點5（POS-09）',
  updated_at  DATETIME(3)         NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (kind, seq)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci
  COMMENT='板子上排與點的名稱（3.13 POS）';
```

- 沒有資料時，App 以預設名稱顯示；儲存時寫入全部 10 筆（INSERT … ON DUPLICATE KEY UPDATE）。App 帳號已有 `flatness.*` 的 SELECT、INSERT、UPDATE 權限，不需要 DELETE。
- 與設備設定在同一個交易內儲存（`store.transaction()`），預覽、確認、套用一起（EDT-03）。
- 資料庫無法連線時，沿用上次讀到的名稱（同 DSC-06 的做法），沒有就用預設名稱。

**不變的部分**：`inspection_point` 的識別（`device_key` + `probe_id`）、允收標準、校準紀錄、BOOTP 對應檔、`key` 的值與格式。

### 5.2 設備設定

DL-EN1 詳細區：

- 位置下拉選單改稱「第 1 台」～「第 10 台」（值仍為 `row-1`～`row-10`）；欄位標題由「位置」改為「編號」。
- `name` 欄位標題改為「DL-EN1 名稱」。

探頭清單由 5 欄改為 7 欄：

```
 ID │ 位置名稱 │ 第幾排 │ 第幾點 │ 校準狀態        │ 校準 │ 允許誤差
────┼──────────┼────────┼────────┼─────────────────┼──────┼─────────
  1 │ 點2      │ 1    ▾ │ 2    ▾ │ 10-13 15:30 已校準│ 校準 │ 0.5 ▾
  2 │ 點4      │ 1    ▾ │ 4    ▾ │ 未校準           │ 校準 │ 0.5 ▾
  3 │          │ 未定 ▾ │ 未定 ▾ │ 未校準           │ 校準 │ 0.5 ▾
```

- 「第幾點」選單中，同一排已被佔用的點停用並標示佔用者，例「3（第 2 台 中排 左）」。只選了排、點仍未定時，該列紅框，訊息區列出「探頭 3：位置須同時設定排與點，或都設為未定」，無法儲存。
- 選定第幾點時，若位置名稱為空，或仍等於原本所選點的名稱，就自動改成新點的名稱（POS-09）；否則不動。
- 新增「位置名稱」區塊（在 DL-EN1 清單上方或另一個分頁，見第 10 節）：

```
 排名稱  [排1    ] [排2    ] [排3    ] [排4    ] [排5    ]   恢復預設
 點名稱  [點1    ] [點2    ] [點3    ] [點4    ] [點5    ]   恢復預設
```

- 名稱 1～10 字，排與排、點與點不可重名，不可空白。
- 確認儲存的變更清單（EDT-03）列出位置變更，例「第 2 台 中排 探頭 1：未定 → 排1 點2」「排1 名稱：排1 → 前排」。

### 5.3 量測主畫面

```
┌ 排1 ──┬──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│       │ 點1          │ 點2          │              │ 點4          │              │
│       │ 第 1 台 前排 │ 第 1 台 前排 │   （空）     │ 第 2 台 中排 │   （空）     │
│       │ 0.012 mm 合格│ …            │              │ …            │              │
├ 排3 ──┼──────────────┼──────────────┼──────────────┼──────────────┼──────────────┤
│       │ …            │ …            │ …            │ …            │ …            │
├ 未設定位置 ┬──────────────┬──────────────┐
│ 請在設備設定│ 探頭 3       │ …            │
│ 設定探頭位置│ 第 2 台 中排 │              │
└────────────┴──────────────┴──────────────┘
```

- 由上而下為第 1～5 排；沒有任何使用中或維修中探頭的排不顯示。
- 每排固定 5 格，第 k 點在第 k 格。空格為淡色虛線框，不顯示任何數值。
- 排頭為排名稱（`plate_position_name`）。
- 「未設定位置」區：位置未定的探頭，依第 N 台、探頭 ID 排列，每列最多 5 格，照常量測與判定。全部探頭都已設定位置時不顯示。
- 方塊：大字為位置名稱（`description`，空白時顯示「探頭 N」），下方小字「第 N 台 DL-EN1 名稱」。其餘內容（測量值、標準值、允收、刻度條、設備狀態）不變（UI-04）。
- UI-11 的縮放：以「排」為單位計算，「未設定位置」區也算一排；每排固定 5 格，比現在的「每排最多 6 個」更容易放下。

### 5.4 設備狀態對應

目前狀態掛在 `DeviceRow`（一台一排）。改成依位置排列後，狀態改為「每台 DL-EN1 → 它的所有方塊」：

| 狀態 | 方塊 | 排頭 | 頂端摘要 |
| --- | --- | --- | --- |
| DL-EN1 偵測不到 | 該台每個方塊：設備異常「DL-EN1 偵測不到」 | 不標示 | 「第 N 台 名稱 偵測不到」 |
| 維修中 | 該台每個方塊灰色「維修中」，不量測、不判定，位置保留 | 不標示 | 「第 N 台 名稱 維修中」（灰色） |
| IP 不符 | 該台每個方塊標示「IP 不符」 | 不標示 | 沿用 DSC-20 的頂端提示 |
| 探頭無回應、未校準 | 只有該探頭 | 不變 | 不變 |

結果橫幅的設備異常原因改用「第 N 台 名稱」稱呼 DL-EN1（例「第 2 台 中排 DL-EN1 偵測不到」）。

### 5.5 3D 繪圖

- 位置：x = 長 ×（點 − 0.5）／ 5，y = 寬 ×（排 − 0.5）／ 5（取代 `plate3d.config.probe_positions` 的平均分佈）。
- 標籤：「排名稱 位置名稱」，例「排1 點2」。
- 拒絕順序：先檢查「使用中」設備是否有未定位置的探頭（POS-07），再檢查有效點數（P3D-02）與同一直線（P3D-03）。維修中設備的探頭不參與檢查。
- 拒絕訊息：

```
無法繪製 3D：有 2 個探頭未設定位置（第幾排、第幾點）。
第 2 台 中排 探頭 3、第 3 台 後排 探頭 1
請工程人員在設備設定設定探頭位置
```

- P3D-03 的「同一直線」判斷不變；只有一排時仍拒絕。

### 5.6 Excel 匯出

- 測量值欄依位置（排、點）排列，未定的探頭排在最後（依第 N 台、探頭 ID）。
- 位置取自匯出當時的設定（量測紀錄不保存位置，見第 10 節第 1 點）。
- 第二工作表（當日標準值）的「位置」欄改為「第 N 台」。
- MAC 欄仍是每台 DL-EN1 一欄。

## 9. 風險與已知限制

- **最多 25 個位置**：排、點各 5 個。探頭超過 25 個的機台，必有探頭未定，無法使用 3D（POS-07）。目前 mosa 有 10 個探頭。
- **升級後 3D 暫時不能用**：既有探頭全部未定，要等工程人員設定位置才能使用 3D；主畫面也會先全部顯示在「未設定位置」區。這是刻意的（不猜位置），但上線前要安排設定。
- **主畫面改動大**：設備狀態從「一台一排」改為「一台對應多個方塊」，是這次最容易出錯的地方，M3 需要完整測試。
- **`name` 意義改變**：DL-EN1 的 `name`（例「前排」）改為設備名稱，既有資料不改值，但畫面上的意思變了，可能需要工程人員重新命名。
- **已簽核需求受影響**：DEF-04、EDT-05、DSC-15、P3D-05、TBD-06 已在規格書加註，需在簽核 POS 時一併確認。
