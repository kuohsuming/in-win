# 提案：探頭偵測與啟用

> 表面平整檢查系統的設定調整。設備設定新增「探頭偵測」：依 DL-EN1 實際連接的放大器數量更新探頭清單。探頭清單新增「啟用」欄：只有啟用的探頭才量測、判定、設定位置、顯示在主畫面與 3D。
> 對應需求：需求規格書 3.14 探頭偵測與啟用 PDT-01～PDT-07（2026-10-15 PO 逐條簽核），並修訂 EDT-06、DEF-04、DEF-05、DEF-06、JDG-02、CAL-01、POS-01、POS-04、POS-07、EXP-03。
> 狀態：rev 1，需求已簽核（2026-10-15）。

---

## 1. 背景

### 1.1 真機確認（2026-10-15，mosa，第 1 台 DL-EN1 192.168.10.21，接 2 台 GT2-N71，每台 1 支探頭）

只送讀取命令。

| 讀取 | 正常 | 拔掉 ID01 的感測頭（斷電後拔、再上電） | 接回後 |
| --- | --- | --- | --- |
| `SR,00,077` 連接台數 | 2 | **2** | 2 |
| `SR,00,000` 整體狀態 | 0 | 32768（bit15 錯誤） | 0 |
| `SR,00,001` 錯誤狀態 | 0 | 1（bit0 = ID01） | 0 |
| `MS` | `02,+241,02,-1939` | `03,+100000000,02,-1936` | `02,+242,02,-1933` |
| `SR,00,669` ID01 錯誤代碼 | 0 | **2（02H 感測頭錯誤 ErH）** | 0 |

- 查詢超出連接台數的 ID（ID03），錯誤代碼回應 0，不是錯誤，所以必須以連接台數判斷有幾個 ID。
- 依 DL-EN1 手冊 2-4：ID 從主模組的放大器起依序分配，不能指定。依 GT2-500 手冊第 7 頁：多通道放大器一個有效接頭一個 ID，DIP 關閉的接頭不分配 ID；有效但未接感測頭的接頭會回報感測頭錯誤。GT2-N71 與 GT2-500 在 DL-EN1 這一層的讀法相同。

### 1.2 問題

- 探頭數量要工程人員手動輸入，容易和實際接線不一致。
- 探頭的 ID 由放大器的實際位置決定：拔掉感測頭 ID 仍在。目前「刪除中間的探頭時後面 ID 往前補」（EDT-06）只有在實際拆掉中間的放大器時才正確；某支探頭壞了或暫時不用時，刪除會讓後面每支探頭的設定對錯一格。
- 實際放大器比設定多時，主畫面把整台判為設備異常（DEF-06），整台不能量測。

## 2. PO 決定（2026-10-15）

| 題目 | 決定 |
| --- | --- |
| 探頭數量 | 新增「探頭偵測」鍵：以當下偵測到的數量為該台的探頭總數；同時保留手動新增、刪除 |
| 偵測範圍 | 只偵測選取（勾選）的那一台，按鍵名稱「探頭偵測」 |
| 實際探頭比設定多、或不想使用某支探頭 | 探頭清單新增「啟用」欄，由工程人員勾選；只有啟用的探頭才能設定第幾排、第幾點，未啟用的為未定；主畫面版面與 3D 只呈現啟用的探頭 |
| 偵測到感測頭錯誤的探頭 | 預設不啟用 |
| 刪除探頭 | 只能刪最後一支；中間的探頭只能取消啟用 |

PO 原話：「當按下重偵測按鍵（新增的）就以當下偵測到的當作目前該台的總數，但同時保留人可以手動新增減少探頭數」；「探頭設定 table 多一個啟用欄位，讓工程人員決定啟用是否勾選，有選用的才可以設置定位點，沒被選到的就設置未定，版面與 3D 繪圖只呈現勾選探頭」；「勾選的那一台，按鍵名稱用探頭偵測」；C、D 皆「是」。

## 3. 設計

### 3.1 資料

- 探頭物件新增選填欄位 `enabled`（布林）；省略為 `true`（啟用）。未啟用的探頭不得有 `row`、`point`。
- 定義檔、JSON Schema、匯入檢查一併支援；升級前的設定全部視為啟用，行為不變。

### 3.2 探頭偵測

- 位置：設備設定，DL-EN1 使用中／維修中的「探頭數量」旁，按鍵「探頭偵測」。
- 讀取：透過主畫面與該台 DL-EN1 已有的連線（DL-EN1 只接受一條連線）讀 `SR,00,077` 與各 ID 的錯誤代碼 `SR,00,(668＋ID)`。只用讀取命令。主畫面倒數或讀值中、偵測設備中時不能按。維修中的設備不連線，按鍵停用並提示。
- 結果（只改畫面上的清單，按「儲存 → 確認儲存」才生效）：
  - 偵測到 N 個 ID、清單 M 列：N > M 從末端新增（名稱「探頭 k」、未定、未校準、允許誤差預設），N < M 從末端移除。
  - 新增的探頭：狀態正常 → 啟用；感測頭錯誤 → 不啟用。
  - 每列顯示偵測狀態：「正常」「感測頭錯誤（未接或故障）」「放大器錯誤（代碼 n）」。
  - 移除時檢查訊息與預覽列出：「將移除：第 1 台 ID 3 右（原第 2 排第 4 點）」，並提示：「若拔掉的是中間的放大器，後面探頭的 ID 會往前補，請確認位置並重新校準」。
  - 偵測不到：提示「偵測不到第 N 台，清單未變更」。
- 演示模式（`--demo`）：示範量測來源回報設定中的探頭數，皆正常。

### 3.3 啟用欄

- 探頭清單新增「啟用」勾選欄（ID 之後）。
- 未啟用：第幾排、第幾點固定「未定」且停用；校準鍵停用。
- 取消勾選：位置立即改為未定（預覽列出原位置）；名稱、允許誤差、校準紀錄保留。重新勾選後位置需再選。
- 「探頭數量」顯示「3（啟用 2）」。
- 某台沒有任何啟用的探頭：檢查訊息提示「第 N 台 名稱 沒有啟用的探頭，主畫面不會顯示這一台的探頭」，仍可儲存。

### 3.4 手動增減

- 「探頭數量」欄與「新增探頭」保留。
- 「刪除探頭」只刪最後一支；選取中間的探頭時按鍵停用，提示「中間的探頭請取消啟用（ID 由放大器的位置決定，刪除會讓後面的探頭對錯）」。
- 「探頭數量」改小同樣只從末端移除。

### 3.5 主畫面、判定、3D、匯出

- 主畫面、「未設定位置」區、3D、Excel 只包含啟用的探頭；未啟用的不讀值、不判定、不寫入量測紀錄（修訂 DEF-04、DEF-05、JDG-02、EXP-03、POS-04、POS-07）。
- 整片合格 = 所有啟用的探頭都合格（JDG-02 的「12 點」改為「所有啟用的量測點」）。
- 偵測設備時（DEF-06）：
  - 連接台數 < 清單中啟用探頭的最大 ID：缺少的啟用探頭標示「探頭無回應」（不變）。
  - 連接台數 > 清單的探頭數：改為提示、不擋量測。頂端提示「第 N 台偵測到 3 支、設定 2 支，請在設備設定按『探頭偵測』」；已設定的探頭照常量測。
  - 未啟用的探頭不檢查。

## 4. 影響範圍

| 模組 | 變更 |
| --- | --- |
| `lan.py`、`bootp.py`、`dl-en1.schema.json`、`positions.py` | `enabled` 欄位與檢查；只列啟用的探頭；預覽列出啟用變更與移除 |
| `dlen1.py`、`measure.py` | 新增讀取探頭清單（連接台數＋各 ID 錯誤代碼）；DEF-06 改為提示；只讀啟用的探頭 |
| `ui/settings_dialog.py` | 「探頭偵測」鍵、啟用欄、刪除限制、數量顯示 |
| `ui/main_window.py`、`plate3d`、`results.py`、`export.py` | 只包含啟用的探頭；DEF-06 提示 |
| 文件 | 規格書、畫面設計規格、操作說明書、HTML 原型、變更紀錄 |

## 5. 驗收

| 編號 | 情境 | 預期 |
| --- | --- | --- |
| AC-1 | 第 1 台清單 1 列，實際接 2 台放大器，按「探頭偵測」 | 清單變 2 列，ID 2 為「探頭 2」、啟用、未定、未校準；儲存後主畫面多一個方塊（在「未設定位置」區） |
| AC-2 | ID01 感測頭拔掉後按「探頭偵測」 | ID01 狀態「感測頭錯誤（未接或故障）」；既有探頭的啟用狀態不變 |
| AC-3 | 清單沒有 ID 3，接上第 3 台放大器但感測頭未接，按「探頭偵測」 | 新增 ID 3，不啟用 |
| AC-4 | 取消勾選已在第 1 排第 2 點的探頭 | 位置變未定且選單停用；預覽列出原位置；儲存後主畫面與 3D 不出現該探頭，整片判定不含它 |
| AC-5 | 選取中間的探頭 | 「刪除探頭」停用並提示改用取消啟用 |
| AC-6 | 設定 2 支、實際 3 台放大器，主畫面偵測 | 不判設備異常；頂端提示請按「探頭偵測」；2 支照常量測 |
| AC-7 | 升級前的設定 | 全部視為啟用，畫面與判定不變 |
| AC-8 | 未啟用的探頭感測頭錯誤 | 不影響整片判定，主畫面不顯示 |

## 6. 實作順序

1. M1 資料：`enabled`、schema、檢查、預覽。
2. M2 讀取：DL-EN1 探頭清單讀取、DEF-06 改提示、只讀啟用的探頭；演示模式。
3. M3 設定頁：探頭偵測鍵、啟用欄、刪除限制、數量顯示。
4. M4 主畫面、判定、3D、匯出只含啟用的探頭。
5. M5 文件、截圖、HTML 原型、變更紀錄。
6. M6 真機確認（mosa 第 1 台：探頭偵測、取消啟用、拔線狀態）。

## 7. 風險

| 風險 | 處理 |
| --- | --- |
| 拆掉中間的放大器，探頭偵測只看到總數變少，從末端移除 | 預覽列出被移除的探頭，並提示中間放大器拆除時須重新確認位置與校準 |
| 感測頭線對調 | DL-EN1 無法分辨，仍靠現場標籤管理（不在本提案範圍） |
| 探頭偵測與量測搶同一條連線 | 只在主畫面閒置時可按，透過同一條連線讀取 |
