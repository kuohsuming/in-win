# 提案：允許誤差改為上限、下限分開設定

> 表面平整檢查系統的判定設定調整。設備設定探頭清單的「允許誤差」由單一對稱值，改為**上限**與**下限**兩個下拉選單；預設上限 +0.2 mm、下限 −0.2 mm。判定沿用 JDG-01：下限 ≤ 讀值 ≤ 上限為合格。
> 對應需求：需求規格書 3.3 JDG-06（修訂，仍待確認）、3.7.1 探頭 `tolerance` 欄改為 `upper`／`lower`、JSON Schema。
> 狀態：rev 1，待 PO 逐條簽核。

---

## 1. 背景與目標

JDG-06（2026-10-07 提出，尚未簽核）讓每個探頭有一個「允許誤差」值，判定為標準值 0、上下限 ± 此值，也就是**對稱**：上限 +t、下限 −t。

實際的表面平整允收不一定對稱：某些工件允許往上凸的量和往下凹的量不同。目前只能設一個對稱值，無法分開。

本提案要做到：

1. 探頭清單的「允許誤差」改為**上限**、**下限**兩個下拉選單，各自獨立。
2. 預設上限 +0.2 mm、下限 −0.2 mm。
3. 判定沿用 JDG-01：下限 ≤ 讀值 ≤ 上限為合格，大於上限偏高，小於下限偏低。
4. 升級後現有設定照常判定（見第 3.4 節）。

## 2. PO 決定（2026-11-17）

| 題目 | 決定 |
| --- | --- |
| 上限、下限的輸入方式 | 兩個下拉選單（沿用現有的固定選項），不開放自由輸入 |
| 範圍限制 | 只要求**下限 ≤ 上限**，不強制一定跨過 0（標準件歸零點） |
| 原本沒設定、沿用舊預設 ±0.5 的探頭 | 套用新預設 ±0.2（上限 +0.2、下限 −0.2） |

PO 原話：「允許誤差設定 改成 上限 與下限設定，預設是上限 +0.2mm 下限是 −0.2mm」。

## 3. 設計

### 3.1 資料

- 探頭物件的 `tolerance`（單一值）改為兩個選填欄位 `upper`（上限）、`lower`（下限），單位 mm。
- 選項（各一份，含正負與 0）：±0.1、±0.2、±0.5、±1、±2、±5、±10、±20、±50、0。上限預設 +0.2、下限預設 −0.2；等於預設值時設定中不寫該欄（與現在 `tolerance` 的做法相同）。
- 規則：`lower` ≤ `upper`。兩者都可為 0、正或負（例如上限 +0.3、下限 +0.1 也允許），只要下限不大於上限。
- **向下相容**：讀取舊設定時，`tolerance: t`（舊欄位）視為上限 +t、下限 −t；沒有任何誤差欄位的探頭，以新預設上限 +0.2、下限 −0.2 判定。

### 3.2 設定頁

- 探頭清單最右邊的「允許誤差」欄改為兩欄：「上限」與「下限」，各一個下拉選單；或同一欄內上下兩個選單（視欄寬，實作時決定，預設拆成兩欄）。
- 上限選單預設 +0.2 mm、下限選單預設 −0.2 mm。
- 下限選到大於上限時，檢查訊息提示「探頭 N 的下限 x 大於上限 y」，不能儲存（JDG-06-A3）。
- 確認畫面列出變更：「探頭 ID 2「右」上限：+0.5 mm → +0.2 mm」「下限：−0.5 mm → −0.3 mm」。

### 3.3 判定、主畫面、3D、匯出

- 判定沿用 JDG-01（下限 ≤ 讀值 ≤ 上限），`lan.standards()` 以 `Standard(0, lower, upper)` 建立，程式其餘部分不變。
- 量測紀錄本來就分別存標準值 0、下限、上限（`inspection_point.lower_limit`／`upper_limit`），不變。
- 主畫面偏高／偏低的註記（超出上限 / 低於下限）、3D 高度放大（P3D-07，以上下限的較大絕對值為基準）沿用現有邏輯，只是上下限不再對稱。

### 3.4 升級

- 沒有資料庫或檔案結構變更（沿用既有的 `dl_en1_config` JSON 與量測紀錄欄位），不需要跑 SQL。
- 升級前的 `tolerance` 欄位仍可讀（視為對稱上下限），所以舊定義檔、舊資料庫設定都照常判定。
- 預設值由 ±0.5 改為 ±0.2：**沒有明確設定誤差的探頭，判定會變嚴**。升級後請品保確認每個探頭的上下限。

## 4. 影響範圍

| 模組 | 變更 |
| --- | --- |
| `bootp.py` | `TOLERANCES` 改為帶正負的選項；驗證 `upper`／`lower` 在選項內且 `lower` ≤ `upper`；保留讀舊 `tolerance` |
| `dl-en1.schema.json` | `tolerance` 改為 `upper`／`lower`（保留 `tolerance` 供舊檔匯入） |
| `lan.py` | `probe_limits(probe)` 取代 `probe_tolerance`：回傳 (lower, upper)，含舊 `tolerance` 與新預設；`standards()`、diff 的誤差比較改為上下限 |
| `ui/settings_dialog.py` | 「允許誤差」欄改為上限、下限兩個選單；驗證下限 ≤ 上限；確認畫面文字 |
| `measure.py`、`results.py`、`export.py`、`plate3d` | 沿用 `Standard.lower`／`upper`，預期不需改（確認 3D 高度放大以較大絕對值為基準） |
| 文件 | 規格書 JDG-06、3.7.1、Schema、畫面設計規格、操作說明書、HTML 原型、變更紀錄 |

## 5. 驗收

| 編號 | 情境 | 預期 |
| --- | --- | --- |
| AC-1 | 新安裝或升級後開啟設定頁 | 每個探頭上限 +0.2、下限 −0.2；舊的對稱 `tolerance` 顯示為 +t／−t |
| AC-2 | 探頭 2 設上限 +0.3、下限 −0.1，儲存 | 讀值 +0.30 合格、+0.31 偏高、−0.10 合格、−0.11 偏低 |
| AC-3 | 下限選 +0.5、上限選 +0.2 | 檢查訊息「下限 +0.5 大於上限 +0.2」，不能儲存 |
| AC-4 | 上限 +0.3、下限 +0.1（同側） | 可儲存；讀值 0（標準件）判為偏低 |
| AC-5 | 匯入舊定義檔（`tolerance: 0.5`） | 探頭上限 +0.5、下限 −0.5，判定不變 |
| AC-6 | 沒設定誤差的探頭 | 以上限 +0.2、下限 −0.2 判定（讀值 0.2001 偏高、−0.2001 偏低） |
| AC-7 | 確認畫面 | 上限、下限各自變更時分別列出 |

## 6. 實作順序

1. M1 資料：`upper`／`lower`、schema、bootp 驗證、`probe_limits`、向下相容。
2. M2 設定頁：上限、下限兩個選單、驗證、確認畫面。
3. M3 判定與其餘模組確認（standards、3D 高度放大、匯出）。
4. M4 文件、截圖、HTML 原型、變更紀錄。
5. M5 真機確認（mosa）。

## 7. 風險

| 風險 | 處理 |
| --- | --- |
| 預設由 ±0.5 改 ±0.2，現有板子合格率下降 | 升級說明請品保逐一確認上下限；舊的明確 `tolerance` 設定保留不變 |
| 兩個選單各 19 個選項（含正負），選取較繁 | 常用的是下限負、上限正；若 PO 要簡化可改為上限只列 0～正、下限只列負～0（即強制跨 0），另立決定 |
| 上下限同側（標準件判不合格）造成混淆 | 檢查訊息提示「此設定下，標準件（讀值 0）會判為偏高／偏低」 |
