# 校準驗證：每次讀值的上限至少 2 個最小單位

- 每次驗證讀值的上限從 ±max(3σ, 解析度) 改為 ±max(3σ, 2 × 解析度)，以 4 位小數來說至少 ±0.0002 mm；5 次平均仍須在 ±容許值（0.002 mm）內。
- 原因：真機靜置時讀值仍會跳 1～2 個最小單位；σ 很小（0.00005）時，原上限只剩 0.00015 mm，正常探頭也會校準失敗。
- 規格書 CAL-04、CAL-A2 修訂，新增 CAL 修訂 5（已簽核）。
