# 探頭偵測與啟用（PDT-01～PDT-07）

- 日期：2026-10-15
- 提案：`docs/pm/probe-detect/PROPOSAL.md`；需求：規格書 3.14（PO 已簽核）。

## 使用者看得到的變更

- **設備設定**：
  - 「探頭數量」旁新增「（啟用 M）」與「**探頭偵測**」鍵。探頭偵測只用讀取命令，讀出選取的那一台實際連接的放大器數量與每個 ID 的狀態，從清單末端新增或移除探頭；新增的狀態正常者啟用、感測頭錯誤者不啟用。儲存後生效。
  - 探頭清單新增「**啟用**」欄，文字為最近一次探頭偵測的狀態。未啟用的探頭位置固定「未定」、不能校準；取消勾選時位置改為未定，預覽列出。
  - 「刪除探頭」只能刪最後一支；中間的探頭請取消啟用（ID 由放大器的位置決定）。
  - 從末端移除的探頭、沒有啟用探頭的設備，列入檢查訊息（仍可儲存）。
- **主畫面、判定、3D、量測紀錄、Excel**：只包含啟用的探頭。
- **偵測設備**：實際放大器比設定多時，不再把整台判為設備異常；頂端黃色提示「偵測到 X 支、設定 Y 支，請在設備設定按『探頭偵測』」，已設定的探頭照常量測。

## 資料與升級

- 探頭物件新增選填 `enabled`（省略為啟用）；未啟用的探頭不可有 `row`、`point`。定義檔、JSON Schema、匯入檢查一併支援。
- 不需變更資料庫；升級後所有探頭視為啟用，行為不變。

## 依據

2026-10-15 真機（mosa 第 1 台 DL-EN1、2 台 GT2-N71）：拔掉 ID01 感測頭後連接台數仍為 2、ID01 錯誤代碼 2（感測頭錯誤 ErH）；接回後恢復。
