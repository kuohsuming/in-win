# 3D 繪圖與板子尺寸

- 結果橫幅新增「3D 繪圖」：以旋轉的立體板子顯示這一片的高低（合格、不合格、量測後的設備異常可按）。只供檢視，不改判定、不寫資料庫。
- 探頭在板子下方，位置依設備設定的第幾排與探頭 ID 平均分佈，標籤為「排名稱 位置名稱」與讀值（與主畫面相同）。
- 兩種模式：「相對標準件」（預設，讀值差）與「扣除傾斜」（平面度，最小平方，只供參考）。高度放大以允許誤差為基準；量測點範圍外的推估區淡化。
- 有效量測點少於 3 個或全部在同一直線上時，按下即以警告訊息拒絕（目前 1 台 2 探頭的設備會被拒絕）。
- 頂端工具列新增「板子尺寸」：設定長、寬、高（mm），存於本機，不需密碼。
- 結果橫幅的按鍵間距改為 12px（畫面設計規格 5.3）。
- 計算以純 Python 實作，不新增套件。開發機（DRP-A100）實測：計算＋第一張圖約 67 ms。
- 畫面設計規格新增 5.11、5.12；操作說明書新增 5.5，截圖重新產生。
