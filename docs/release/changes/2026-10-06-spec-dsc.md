# 規格書：新增 3.10 設備網路探索與設備分類（DSC），DL-EN1 設定改以資料庫為主檔

- 新增 DSC-01～DSC-07：App 執行緒記錄設備網路上發出 BOOTP／DHCP 的所有設備（每個 MAC 一筆）；設備清單與四種狀態（未分類／DL-EN1 使用中／DL-EN1 已停用／非 DL-EN1）；使用中可完整設定、非 DL-EN1 只能設 IP；資料庫斷線不遺失；App 啟動時由資料庫產生 `dl-en1.json` 與 BOOTP 主機對應；dnsmasq 由 App 啟動與管理，作業系統開機不啟動。
- 連帶修訂：DEF-01 唯一來源改為資料庫 `lan_device`（定義檔改為產生的副本）；上傳定義檔改為匯入資料庫；安裝包遮蔽 `dnsmasq.service`、產生 root 擁有的主設定、sudoers 只允許固定參數執行 dnsmasq；資料表增為三張。
- 順帶修正 V0 指出的矛盾：`config.toml` 不再存放 DL-EN1 IP（NFR-12、3.0.6）。
- 簽核：solo PO approve @ 2026-10-06；待決事項採建議值（見 3.10 簽核紀錄）。

尚待實作同步（code ↔ spec drift）：`installer/steps/03-bootp.sh` 仍設定 dnsmasq 開機啟動；App 設備設定目前直接寫定義檔而非資料庫；`sql/in-win.sql` 尚無 `lan_device`。

## 追加（同日）：IP 設定

- DSC-08：設定 IP 時預先填入未佔用的 IP（依設備網卡網段；DL-EN1 預設 `.11～.99`、非 DL-EN1 `.100～.199`），輸入與套用時檢查佔用並顯示佔用者。
- DSC-09：已停用的 DL-EN1 不佔用 key、名稱與 IP；改回使用中時重新檢查。
- DSC-10：以 ping ＋ ARP 鄰居表實際探測 IP 是否被網路上其他 MAC 使用；設備本身不算佔用；未接線時只提示不阻擋。
- DSC-11：設備網段改變時，標示 IP 不在網段內的設備並須修正後才能套用。
- DSC-01：出現次數改為每收到一個 BOOTP／DHCP 請求封包加 1。
