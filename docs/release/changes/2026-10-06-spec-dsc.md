# 規格書：新增 3.10 設備網路探索與設備分類（DSC），DL-EN1 設定改以資料庫為主檔

- 新增 DSC-01～DSC-07：App 執行緒記錄設備網路上發出 BOOTP／DHCP 的所有設備（每個 MAC 一筆）；設備清單與四種狀態（未分類／DL-EN1 使用中／DL-EN1 已停用／非 DL-EN1）；使用中可完整設定、非 DL-EN1 只能設 IP；資料庫斷線不遺失；App 啟動時由資料庫產生 `dl-en1.json` 與 BOOTP 主機對應；dnsmasq 由 App 啟動與管理，作業系統開機不啟動。
