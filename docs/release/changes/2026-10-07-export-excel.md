# 取出測試數據：產生 Excel

- 「取出測試數據」→「選擇位置並儲存」現在會產生 `平整檢查_YYYY-MM-DD.xlsx`；之前只顯示「尚未實作」，沒有檔案。
- 工作表一「量測紀錄」一片一列：編號（文字格式）、量測時間、判定、重讀次數、各量測點測量值、不合格點。偏高、偏低的儲存格為紅底，設備異常的點寫「異常」並以黃底標示。
- 工作表二「當日標準值」列出各點的標準值與上下限；同一點當日改過標準時，每一組各列一行。
- 資料來源為資料庫，加上尚未寫入資料庫的本機暫存，不會重複。
- 預設資料夾為上次儲存的位置（EXP-02）。寫出失敗（例如隨身碟已拔除）時，在視窗內顯示原因，不中斷量測（EXP-04）。
- 開發環境補裝 `openpyxl==3.1.5`（requirements.txt 原本就已鎖定此版本）。
- 修正：存檔後要顯示「已儲存」提示時出錯，視窗沒有關閉也沒有提示，看起來像沒存成功；其實檔案已經產生。現在存檔後視窗會關閉，並顯示「已儲存 N 筆：路徑」。
- 改版（EXP-02 修訂，已簽核）：不再跳出系統另存新檔視窗。改成在「取出測試數據」視窗內直接修改檔名（預設 `平整檢查_YYYY-MM-DD`）和存放資料夾（按「變更資料夾」）。
  - 同名檔案要再按一次「覆蓋儲存」才會取代。
  - 存好後視窗不關閉，顯示「已儲存 N 筆」與完整路徑，並出現「開啟資料夾」鍵，可直接用檔案總管打開。
- 修正：按「變更資料夾」選的資料夾沒有生效，檔案仍存到家目錄。可能是系統的選擇視窗在全螢幕下被擋住，或選擇結果沒有傳回。
  - 「變更資料夾」改用 App 內建的視窗，固定顯示在最上層。
  - 資料夾欄位可以直接輸入或貼上路徑；資料夾不存在時不能儲存。
  - 變更資料夾會記錄在日誌。
- 新增（EXP-03 修訂，已簽核）：「量測紀錄」工作表最右邊每排 DL-EN1 一欄 MAC（例「前排 DL-EN1 MAC」），取自量測當時寫入的 MAC（DAT-06）；當日換過設備時，換機前後的各片顯示各自的 MAC。
