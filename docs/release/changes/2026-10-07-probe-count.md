# 探頭數量決定探頭清單

- PO 提出：設定頁的探頭數量改變時，下方探頭清單跟著增減，並可儲存。
- 「最多探頭數」改名「探頭數量」；增加時末端新增（ID 接續、預設名稱「探頭 N」），減少時移除末端。
- 探頭 ID 自動編號 1～N、不可手動修改；「刪除探頭」刪除選取列後 ID 往前遞補，數量減 1；「新增探頭」等同數量加 1。儲存時 `max_probes` = 探頭數。
- 修正：選取探頭列時「刪除探頭」未啟用（狀態只在其他操作時更新）。
- 規格書新增 EDT-06（G1、A1～A3），3.7.1 `max_probes` 說明、EDT-01、DSC-12 同步；畫面設計規格 5.10 同步。
