# 探頭位置：每個探頭設定第幾排、第幾點（實作）

- **資料**：探頭設定新增選填 `row`、`point`（1～5，同時存在或同時省略）；定義檔頂層新增 `position_names`（排名稱、點名稱）。新資料表 `plate_position_name`；`inspection_point` 新增 `pos_row`、`pos_point`、`row_name`（量測當時的位置）。位置不重複分兩層檢查：定義檔（`bootp.validate`）與設定頁全體（`lan.validate`，含維修中）。名稱與設備設定同一交易寫入，資料庫無法連線時沿用定義檔中的名稱。
- **設備設定**：DL-EN1 改稱「第 N 台」、`name` 為「DL-EN1 名稱」；探頭清單新增「第幾排」「第幾點」下拉選單（未定、1～5；佔用者停用並標示、整排已滿標示、改排時衝突自動改回未定），選點時自動帶入點名稱；探頭清單下方新增「排與點名稱」區塊（全機共用，可恢復預設）；只改名稱也能儲存；確認畫面列出位置與名稱變更。第一次設為 DL-EN1 時探頭預設名稱改為「探頭 1」～「探頭 4」。
- **主畫面**：依探頭位置排列第 1～5 排、每排固定 5 格（空格虛線框），位置未定的在最下方「未設定位置」區；方塊小字顯示「第 N 台 名稱」；DL-EN1 偵測不到、整台設備異常、維修中、IP 不符標在該台每個方塊上，頂端另有提示；橫幅以「排名稱 位置名稱」稱呼探頭。縮放改為以列計算，並修正縮放時排高沿用上一個比例的問題。
- **3D 繪圖**：位置改為固定 5 × 5 格；任一使用中探頭位置未定時拒絕並列出探頭；P3D-03 的訊息改為「…（例如都在同一排，或都在同一點），探頭須分佈在不同的排與點。」
- **Excel**：測量值欄依量測當時的位置排列，標題為「排名稱 位置名稱」（未定為「第 N 台 名稱 位置名稱」，同名加註）；第二工作表加「位置」欄。
- **文件**：需求規格書 3.7.1 內嵌 JSON Schema 與程式同步；畫面設計規格、實作對照、操作說明書（截圖、PDF）、HTML 原型更新。
- **升級**：部署前先執行 `sudo mysql < sql/in-win.sql`（可重複執行）。不支援換回舊版。升級後既有探頭位置皆為未定，主畫面全部在「未設定位置」區、3D 拒絕，請在設備設定設定位置。
