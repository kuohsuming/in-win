# 修正橫幅「不合格」下緣被「FAIL」蓋住

- 真機上「不合格」的下緣被裁切、緊貼「FAIL」。原因：橫幅高度固定 190px，內容區約 138px；中文字型以行高排版時 112px 大字約需 162px、副標約 58px，放不下而被壓縮。
- 修正：大字與副標改以字形實際上下範圍排版（`TightText`），不含字型行高的上下留白；橫幅上下內距由 22px 改為 14px。112px 的「不合格」＋「FAIL」約需 151px，放得進固定高度。
- 新增維護用畫面擷取：`kill -USR1 <App pid>` 將目前畫面存到日誌目錄（`screen-日期-時間.png`）；Wayland 下外部程式無法擷取 App 畫面，供遠端確認實際顯示。
- 新增測試：各橫幅狀態（不合格、合格、設備異常、待放置、偵測設備中、倒數）在縮放範圍內大字與副標皆完整、不重疊。
- 規格書 UI-11-A5 補充橫幅。
