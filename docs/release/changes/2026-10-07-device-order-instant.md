# 上移／下移按下即儲存，主畫面同步調整順序

- PO 決定：設備設定的「上移」「下移」按下即儲存，不需按「儲存」、不經差異預覽；主畫面不提供調整按鍵。
- 每按一次即寫入 `lan_device.sort_order` 並更新 `dl-en1.json`；主畫面只調整排的上下順序，畫面上的量測結果保留；只寫入順序，其他尚未儲存的編輯不受影響；寫入失敗時順序不變並說明原因。
- BOOTP 主機對應改依狀態與 IP 排序，與畫面順序無關，調整順序不需重新啟動 dnsmasq。
- 規格書：DSC-17 改寫（撤回 A2，新增 A4、A5）；EDT-02 註明「隱藏」與「上移／下移」為按下即儲存的例外；DSC-12 不再包含排列順序。
