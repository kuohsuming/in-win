# 設備設定與取出測試數據視窗置於主畫面中央

- 新增需求 UI-09（含 G1、A1、A2）：點擊工具列按鍵開啟的視窗置於主畫面中央；改變大小後仍置中。
- 原因：App 在 Wayland 下執行，程式指定的視窗座標被忽略，視窗未對齊主畫面；設備設定由密碼步驟放大後也不會重新置中。
- 做法：對話框改為嵌入主畫面的遮罩元件內（`widgets.Backdrop.host()`），不另開視窗；對話框或主畫面改變大小時重新置中。
- 畫面設計規格 5.8、5.10、第 9 節同步註明。
