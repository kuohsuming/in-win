# 「DL-EN1 維修中」保留在主畫面，不量測

- PO 修訂 DSC-15：維修中的 DL-EN1 仍顯示在主畫面原位置，灰色標示「維修中：不連線、不量測」；不列入偵測、量測與判定，整片結果只依使用中的量測點，也不寫入量測紀錄。與「已停用」（不顯示）區分。撤回 DSC-15-A1，新增 A4、A5。
- 使用中與維修中共用主畫面順序，「上移」「下移」兩者皆可用（DSC-17）；設備設定清單中兩者依主畫面順序排列（DSC-02）。
- `dl-en1.json` 仍只含使用中（連線用）；主畫面版面另由資料庫產生（`lan.screen_layout`）。資料庫無法連線時只能依 `dl-en1.json` 顯示，維修中的排暫不顯示。
- 差異預覽：改為維修中的量測點列為「主畫面保留但不量測」，不再列為「將從主畫面移除」。
- 畫面設計規格 5.4 新增維修中的排樣式，5.10 設備類型表與清單排序同步更新。
