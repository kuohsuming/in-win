# ARP 探測結果只提示，不阻擋儲存

- PO 決定：「不管設備是否實際存在都可以儲存」。ARP 探測中、或探測到網路上其他 MAC 使用此 IP 時，儲存鍵仍可用。
- 探測到佔用時：欄位下方以警告色顯示回應者 MAC；檢查訊息列出「⚠ …（仍可儲存）」；確認儲存頁列出「網路上已有其他設備使用下列 IP，儲存後可能發生 IP 衝突」。
- 資料表中的 IP 重複（DSC-08）與其他設定錯誤仍阻擋儲存。
- 規格書 DSC-10 改寫：撤回 G1，新增 G2、A5、A6；畫面設計規格 5.10 同步。
