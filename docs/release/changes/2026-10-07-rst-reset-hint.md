# IP 變更後提示按 RST 3 秒重設，取代「重新上電」

- 真機驗證：DL-EN1 斷電重開沿用保存的 IP、不送 BOOTP；按住 RST 3 秒後送出 BOOTP 並取得主機對應中的 IP。原本「需將下列設備重新上電才會取得新 IP」的提示無效。
- 設定確認頁改為「請按住下列 DL-EN1 上的 RST 鍵 3 秒重設，才會取得新 IP」；儲存後的提示同步。其他設備（例如筆電，以 DHCP 取得 IP）另列「須重新連線或重新上電」。
- 設備實際使用的 IP（ARP 位址偵測封包）已是新 IP 時不列入（例如設為 DL-EN1 時沿用實際 IP）。
- 差異預覽「最多探頭數」改為「探頭數量」（EDT-06）。
- 規格書 DEF-03、3.8.1 步驟 7、UPL-05、UPL-09、DSC-14-G1 修訂並簽核；畫面設計規格同步。
