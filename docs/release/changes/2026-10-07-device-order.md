# 上移／下移的順序同時決定主畫面與設定頁，重新啟動後不變

- 新增需求 DSC-17（含 G1、A1～A3）：設備設定的「上移」「下移」調整「DL-EN1 使用中」的順序，主畫面與設備設定清單共用此順序；儲存時寫入 `lan_device.sort_order`，未儲存不改變；App 重新啟動後保持不變。
- 現有實作已符合，新增端到端測試：上移兩次 → 儲存 → 模擬 App 重新啟動，檢查定義檔、主畫面與設定頁三處順序；另測未儲存即關閉不改變、只有使用中可移動。
- 需求追溯表與畫面設計規格 5.10 同步更新（另補上 UI-09）。
