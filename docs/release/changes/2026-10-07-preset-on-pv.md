# 校準：預設資料選擇改為 P.V.，讀回的歸零基準須相符

- 真機校準發現放大器預設資料選擇（148）為 R.V. 時，歸零連原始值 R.V. 一起改變，記下的歸零基準都是 0，偵測時無法發現歸零遺失（CAL-10）。
- 校準第 1 步改為把 148 設為 1（P.V.）：歸零只作用於判斷值，R.V. 保持原始值。
- 驗證時加讀歸零基準（R.V. − P.V.），與 20 次取樣平均相差超過容許值就判定失敗，並清除放大器的歸零。
