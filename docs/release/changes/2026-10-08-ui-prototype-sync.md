# HTML UI 原型依 App 現況更新

`docs/ui/prototype/board-station.html` 改為與 App 2026-10-08 版的畫面與操作一致：

- 主畫面：標準值 0、允收 ±允許誤差（每個探頭）；排名稱下方顯示「第 N 排」；按「下一片」「重讀」後等待 0.5 秒（不倒數，顯示「讀取中／請勿移動表面」）；探頭磚的數值區改為左測量值、右標準值與允收，註記在設備狀態列右側。
- 新增樣本畫面：設備啟動中、探頭未校準、IP 不符（DSC-20）；維修中的排以虛線框顯示（DSC-15）。移除「未設定允收標準」。
- 取出測試數據：日期、檔名（可修改）、存放資料夾與「變更資料夾」、同名檔案「覆蓋儲存」、儲存後視窗不關閉並出現「開啟資料夾」。
- 設備設定：兩欄均分；位置下拉選單（第 1～10 排）取代識別碼；TCP 埠隱藏；探頭數量；探頭表加入「校準」狀態、「校準」按鍵與「允許誤差」下拉選單（預設 0.5 mm）；清單「刪除」、上移／下移適用所有設備並立即儲存；儲存有錯時列出錯誤；差異預覽列出允許誤差變更與 RST 重設提示。
- 探頭校準：確認 → 校準中（可取消）→ 結果（取樣、驗證、歸零基準），結果立即寫入並重建主畫面。
