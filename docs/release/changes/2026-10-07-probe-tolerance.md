# 探頭允許誤差：在設備設定選擇，取代 config.toml 的上下限

- 設備設定的探頭清單最右邊新增「允許誤差」選單：5、10、20、50、100、200 mm，預設 5 mm。
- 判定改為標準值 0、上下限 ± 允許誤差，也就是 |讀值| ≤ 允許誤差為合格。`config.toml` 的 `[standards.*]` 不再使用，已從範本移除。
- 存於 `probes[].tolerance`，等於預設 5 mm 時不寫入；定義檔 schema 與檢查同步。按「儲存」後生效，確認畫面會列出「允許誤差：5 mm → 20 mm」。
- 每個探頭都有允收標準，不再出現「未設定允收標準」（DEF-09 撤銷）。
- **注意**：原本的暫定上下限是 ±0.050 mm，改版後預設為 ±5 mm，判定會寬鬆很多，請依實際需求設定各探頭。
- 規格書新增 JDG-06（**待 PO 簽核**），JDG-05、DEF-09 劃線取代；3.7.1、TBD-01、畫面設計規格同步。
