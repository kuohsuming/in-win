# 上移／下移適用清單中任何設備

- PO 決定：上移／下移不論設備類型皆可使用；選取的設備在最上面時「上移」停用、最下面時「下移」停用，其餘兩鍵皆可用。
- 所有設備共用一個順序（`sort_order`）；主畫面取其中使用中與維修中的相對順序。第一次調整時依目前清單順序全部重新編號。
- 按下即儲存，只寫入順序；尚未儲存的設備類型變更也可調整順序，類型仍待「儲存」時寫入。
- 採用的建議值：新偵測到的不明設備排在最上面；改變設備類型時位置不變；尚未排序的設備第一次設為 DL-EN1 時排到最後；替換時新機接手舊機的位置，舊機移到新機原本的位置。
- 規格書 DSC-17、DSC-02 改寫，新增 DSC-17-A6、A7；畫面設計規格 5.10 同步。
