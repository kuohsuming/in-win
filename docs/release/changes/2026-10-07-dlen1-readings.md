# 連線 DL-EN1 實機讀取探頭數值

- 新增 `app/flatness/dlen1.py`：每台 DL-EN1 一條常駐 TCP 連線（埠預設 64000，斷線自動重連），只用讀取命令（`SR`、`FR`、`MS`，不送 `SW`）。
  - 偵測：讀連接台數（077）、整體狀態（000，非 0 時讀 008／009）、每個探頭的小數位數（`FR,nn,037`）；連接台數少於已安裝探頭 ID 時該探頭「放大器未連接」，多於探頭數量時整台「探頭台數超出定義」（DEF-06）；輸出狀態 03 時讀放大器錯誤代碼；`ER,**,031／254` 為設備啟動中。
  - 讀值：`MS` 第 N 組對應放大器 ID N，只處理已安裝的探頭（DEF-05）；特殊值為「無有效數據」。
  - 各台平行處理；連線 3 秒內未建立為偵測不到（DEV-04）。
- App 預設使用實機；`--demo` 改用示範量測來源（`scripts/run-dev.sh` 假 dnsmasq 模式自動加上）。
- 主畫面處理整台設備異常（本機錯誤、探頭台數超出定義）：該排所有探頭顯示設備異常與原因。
- 真機驗證：偵測約 0.1 秒、讀值約 3 毫秒，數值 −0.2971／+0.0358；DL-EN1 同一時間只接受 1 條連線，重建設定時先關閉舊連線。
- 規格書 5.1 記錄真機回應與單一連線限制。
