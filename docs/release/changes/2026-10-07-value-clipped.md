# 修正主畫面測量值被裁切

- 真機讀值時「-0.297」只顯示上半部。原因：排高在空白狀態決定，之後出現結果時方塊需要更多高度——數值與「mm」混排的行比單獨的「—」高、設備狀態列多了紅字說明（18px）、排的邊框（1px）未計入排高——方塊被壓縮，測量值被裁切。
- 修正：依「-88.888 mm」預留測量值高度、依紅字說明預留設備狀態列高度；排的邊框加粗（偵測不到、IP 不符 4px）時以內距補足，排與探頭方塊高度在各狀態下相同。
- 新增測試：1、4、6 排在空白、合格、偏低（含說明）、無數據、偵測不到、IP 不符各狀態下，探頭方塊與測量值皆不小於所需高度；4 排在 1080p 仍不需捲動。
- 規格書 UI-11 新增 A5。
