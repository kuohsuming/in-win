# 探頭校準改為放大器歸零（斷電後保留）

- 校準流程改為寫入放大器，只對選取的探頭（放大器 ID）：
  1. 讀出放大器的預設記憶（149）、預設資料選擇（148）、執行點（150）、通道 0～3 預設值（067／072／077／082），原本的值記入日誌；不是「YES、R.V.、全部通道通用、0」的才寫入。
  2. 第一步清除之前的歸零（`SW,ID,002,+000000001`）。
  3. 讀 20 次判斷穩定，間隔取 50 毫秒和放大器響應時間（132）中較長的。
  4. 放大器歸零（`SW,ID,001,+000000001`），斷電後仍保留。
  5. 再讀 5 次驗證（條件不變）。
  6. 失敗或取消時，若已歸零就再清除一次。
- 不再有「採用」：放大器的歸零清除後，資料庫立即跟著更新。通過時記下歸零基準（R.V. − P.V.）；失敗或取消時清除，探頭為「未校準」。清除前就失敗（例如讀取設定失敗）時，放大器和資料庫都不變。
- 量測直接使用放大器的值（P.V.），App 不再扣除偏移量；`inspection_point.zero_offset` 記錄量測當時的歸零基準。
- 偵測設備時以 `SR,ID,037／038` 比對歸零基準和資料庫紀錄，相差超過容許值時，該探頭顯示「歸零遺失」或「歸零已變更」，不量測（CAL-10）。
- NFR-11：`SW` 只在校準時、只寫入上述資料編號；仍禁止 003 重置、005 初始化重置。`Link` 支援 `SW` 的回應格式（`SW,ID,資料編號`）。
- **升級注意**：既有軟體校準記錄的偏移量和放大器不符，偵測時會顯示「歸零遺失」，須重新校準。
- 規格書：修訂 CAL-02、CAL-03、CAL-05、CAL-06、CAL-08、CAL-09、NFR-11、5.1；新增 CAL-10、CAL-G3、CAL-A8～CAL-A10；撤銷 CAL-A1。已簽核。SQL 欄位註解與畫面文件同步更新。
