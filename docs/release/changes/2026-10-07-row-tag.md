# 主畫面排標示改為「第 N 排」

- 主畫面每排左欄的 DL-EN1 標示由畫面序號「DL-EN1 #n」改為位置標籤「第 N 排」（EDT-05），與設定頁清單一致；偵測不到、維修中、IP 不符的標籤與 IP 不符提示同步改用「第 N 排」。例如設定第 1、3、5 排時，主畫面顯示第 1、3、5 排，不再是 #1、#2、#3。
- 規格書：DSC-08-G1、DSC-09-G1 移除「套用鍵停用」，改為儲存鍵仍可按、按下時列出錯誤不寫入（EDT-04）；DSC-19、DSC-20、NFR-14 簽核。畫面設計規格同步，新增 IP 不符的樣式。
