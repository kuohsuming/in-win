# 沿用設備實際使用的 IP；主畫面標示 IP 不符並提示按 RST 3 秒

- 設定頁將設備設為「DL-EN1 使用中」、「維修中」或「其他設備」時，若設備已有實際使用的 IP（ARP 位址偵測封包）且可用（在網段內、非網路／廣播位址或量測 PC、未被其他設備佔用），IP 預設沿用它，設備不必重設；否則照舊取預設範圍內最小的空位。
- 主畫面：使用中或維修中的 DL-EN1 實際使用 IP 與設定不同時，該排以警告色粗框與「IP 不符」標示；頂端狀態列以警告色提示實際與設定的 IP，並請作業員按住該台 DL-EN1 的 RST 鍵 3 秒重設；收到與設定相同的 IP 後自動消失；寫入日誌。
- 真機觀察：DL-EN1 取得 IP 後每 3 分鐘送 1 個 ARP 宣告；按 RST 的測試在日誌中看不出重設（無 BOOTP、IP 與節奏不變），待再測。
- 規格書：DSC-08 修訂（已簽核）、新增 DSC-19-G4 與 DSC-20（待確認）。
