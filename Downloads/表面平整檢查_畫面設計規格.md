# 表面平整檢查 作業員畫面設計規格

本文件把畫面原型（`board-station.html`，與本文件一起提供）的版面、顏色、字型、元件與狀態轉成文字，供開發實作。畫面上的排與探頭完全依 DL-EN1 定義檔（`dl-en1.json`）動態產生，相關規則見需求規格書 3.7、3.8。數值以原型為準；原型中最上方的「樣本畫面」切換列只供展示，正式版不實作。

---

## 1. 目標裝置與設計原則

| 項目 | 規格 |
| --- | --- |
| 解析度 | 1920 × 1080，全螢幕（無視窗標題列） |
| 觀看距離 | 作業員站立，距螢幕 1～2 公尺 |
| 語系 | 繁體中文；字型必須離線可用（不可依賴網路字型） |
| 操作 | 觸控或滑鼠；作業員只使用「重讀」「下一片」兩顆大按鍵 |

設計原則：

1. **結果優先**：結果橫幅是全畫面最醒目的元素，一眼即可判斷能否放行。
2. **不只靠顏色**：合格、偏高、偏低、異常各有不同形狀的圖示與文字，色弱也能分辨。
3. **非合格一律紅色並標 FAIL**：超出規格與設備異常都用紅色，以文字與圖示區分原因。
4. **錯誤點最醒目**：不合格時，問題點加粗紅框，合格點淡化。
5. **不可誤導**：資料不完整或設備異常時絕不顯示綠色合格。

## 3. 字型

| 代號 | 字型堆疊 | 用途 |
| --- | --- | --- |
| 文字字型 | Noto Sans TC → Noto Sans CJK TC → PingFang TC → Microsoft JhengHei → sans-serif | 所有中文與一般文字 |
| 數字字型 | Barlow Semi Condensed → 文字字型 | 編號、時間、測量值、標準值、允收範圍、倒數秒數 |

- Ubuntu 上以 `fonts-noto-cjk` 提供 Noto Sans CJK TC；Barlow Semi Condensed（SIL OFL）隨 App 附帶字型檔，以 `QFontDatabase.addApplicationFont()` 載入。
- 所有數字使用**等寬數字**（tabular figures），數值變動時不跳動。
- 字重：400 一般、500 中等、700 粗、900 特粗（結果大字、排名稱、狀態徽章）。

| 項目 | 規格 |
| --- | --- |
| 內容最大寬度 | 1600px，水平置中 |

**淡化規則**：整片判定為不合格或設備異常時，所有「合格」方塊透明度降為 55%，讓問題點最醒目。

### 5.6 刻度條

高 34px，以百分比定位：

| 部位 | 規格 |
| --- | --- |
| 底線 | 全寬，距頂 14px，高 6px，`line`，圓角 3px |
| 允收區間 | 左 20%～右 80%（佔中間 60%），距頂 10px，高 14px，`go` 透明度 35%，圓角 2px |
| 標準值線 | 50% 位置，距頂 7px，寬 2px、高 20px，`ink-2` |
| 測量值指標 | 向下三角形，寬 18px、高 13px，尖端朝下，顏色同測量值 |

指標水平位置：

```
區間寬 = (上限 − 下限) ÷ 0.6
起點   = 下限 − 區間寬 × 0.2
位置%  = (測量值 − 起點) ÷ 區間寬 × 100，限制在 2%～98%
```

註：標準值線固定畫在 50%，標準值不在上下限正中央時與實際位置略有偏差，原型即如此處理。

| 項目 | 規格 |
| --- | --- |
| 尺寸 | 寬 1120px（最大 96% 螢幕寬），高度最大 92% 螢幕高；模態，背景遮罩黑色 45% |
| 結構 | 標題列（固定）／內容區（可捲動）／按鍵列（固定） |
| 標題列 | 「編輯 BOOTP 設備（DL-EN1 定義檔）」20px；右側「✕」關閉鍵（22px，`ink-2`）；下方 1px `line` 分隔線；內距 16px 22px |
| 內容區 | 內距 16px 22px，區塊間距 18px；區塊標題 17px 粗體，右側可接 13px `ink-2` 說明 |
| 按鍵列 | 上方 1px `line` 分隔線，內距 14px 22px；左側為次要功能，右側為「取消」與主要按鍵 |
| 按鍵樣式 | 一般：16px，內距 9px 16px，邊框 2px `ink-2`，背景 `panel-2`，圓角 6px；主要：背景 `ink`、文字 `panel`；危險：邊框與文字 `ng`、背景 `panel`；小型：14px，內距 5px 10px，邊框 1px；停用透明度 35% |
| 輸入框 | 16px，內距 6px 8px，邊框 2px `line`，背景 `panel`，圓角 4px；數值、MAC、IP 用數字字型 17px；錯誤時邊框 `ng`、背景 `ng-soft` |

**步驟一：密碼**

- 「工程人員密碼」密碼輸入框（最寬 360px），下方 13px `ink-2` 說明：「此功能會變更 DL-EN1 的 IP 配發與畫面配置，限工程人員使用。」
- 按鍵：「取消」「確認」。未輸入時輸入框標紅，不進入下一步。

**步驟二：編輯**

1. **網路上偵測到的 BOOTP 設備**（表格，標題右側「重新整理」小按鍵）

| 欄位 | 內容 |
| --- | --- |
| MAC 位址 | 數字字型 |
| 目前 IP | 已配發的 IP；尚未配發顯示「未配發」 |
| 最後請求 | 最後一次 BOOTP 請求時間（時:分:秒） |
| 狀態 | 標籤：已定義為綠底綠字「已定義：前排」；未定義為紅底紅字「未定義」（13px 粗體，內距 2px 8px，圓角 3px） |
| 操作 | 未定義者顯示小按鍵「新增為 DL-EN1」 |

資料來源為 dnsmasq 的 BOOTP 請求紀錄；表格列與表頭以 1px `line` 分隔，表頭 13px `ink-2`。

2. **DL-EN1 定義（共 N 台）**：每台一張卡片，依畫面順序排列。

| 部位 | 規格 |
| --- | --- |
| 卡片 | 背景 `panel-2`，邊框 2px `line`（有錯誤時 `ng`），圓角 6px，內距 12px 14px |
| 卡片標題列 | 「#序號」數字字型 `ink-2` ＋ 名稱 18px 粗體；右側小按鍵「上移」「下移」「刪除此 DL-EN1」（危險樣式；第一台停用上移、最後一台停用下移；刪除前確認） |
| 欄位列 | 六欄：識別碼 key、名稱 name、MAC、IPv4、Port、最多探頭數；欄寬比例 1 : 1 : 1.4 : 1.3 : 0.8 : 0.8；欄位標籤 13px `ink-2` 在輸入框上方；MAC 輸入框提供偵測到的 MAC 下拉建議；Port 空白時顯示淡字「64000」 |
| 探頭列表 | 表頭「探頭編號 id｜位置名稱 description」；每列三欄：編號（90px）、位置名稱（填滿）、「刪除」小按鍵（危險樣式）；列表下方「＋ 新增探頭」，自動帶入最小未使用編號與名稱「探頭 N」 |

卡片列表下方為「＋ 新增 DL-EN1」按鍵。新增時自動帶入：key `dlen1-N`、名稱「設備 N」、設備網段內第一個未使用的 IP（由 .11 起）、最多探頭數 4、探頭 1～4。由偵測表「新增為 DL-EN1」新增時另帶入該 MAC。

3. **檢查結果**（內容區最下方，隨輸入即時更新）

- 有錯誤：紅框紅底區塊，「尚有 N 項錯誤，修正後才能套用：」並逐條列出（例：「第 3 台（後排） IPv4 與第 2 台重複」），對應輸入框同時標紅。
- 無錯誤：綠框綠底「檢查通過，可以預覽並套用。」

檢查規則：key 為小寫英數與連字號 1～30 字；name 1～10 字；MAC 為 `XX:XX:XX:XX:XX:XX`；IPv4 格式正確、在設備網段、非 .0／.255、不同於量測 PC；Port 空白或 1～65535；最多探頭數 1～15；至少 1 個探頭且不超過最多探頭數；探頭編號為 1～最多探頭數且同台不重複；位置名稱 1～10 字；key、name、MAC、IPv4 在所有 DL-EN1 間不可重複；DL-EN1 為 1～8 台。

按鍵列：左側「上傳定義檔」（選擇 `.json`，64 KB 以內，載入後進入編輯畫面供檢查）、「下載定義檔」（另存目前編輯內容）；右側「取消」、「預覽並套用」（有錯誤時停用）。

**步驟三：預覽**

| 部位 | 規格 |
| --- | --- |
| 變更清單 | 每項一個區塊（背景 `panel-2`，邊框 1px `line`，圓角 6px，內距 10px 14px，15px，行高 1.6）；開頭標示「新增」（`go`）、「變更」（`ink`）、「移除」（`ng`）、「順序」；MAC 與 IP 的變更以紅底紅字粗體標示 |
| 變更比對 | 以 key 對應新舊 DL-EN1；比對名稱、MAC、IP、Port、最多探頭數、探頭新增／移除／改名，以及畫面排列順序 |
| 影響區塊 | 紅框紅底：「需將下列 DL-EN1 重新上電才會取得新 IP」（新增者與 MAC 或 IP 變更者）、「下列探頭尚未設定允收標準，量測時將顯示設備異常」、「下列量測點將從畫面移除」 |
| 按鍵 | 「返回修改」、「確認套用」（無任何變更時停用） |

**套用後**：關閉對話框 → 寫入定義檔並產生 BOOTP 對應、重啟 dnsmasq（正式版，失敗時自動還原）→ 清除目前編號與重讀次數 → 依新定義重建主畫面 → 自動執行偵測設備；提示訊息「已套用定義檔並更新 BOOTP 對應；請將 後排、設備 4 重新上電」。

## 9. PySide6 實作對照

| 原型做法 | PySide6 做法 |
| --- | --- |
| CSS 色票變數 | 於 Python 定義色票表，產生 QSS 字串；深淺主題各一份 |
| `class="probe hi"` 等狀態 | `setProperty("state", "hi")` 後 `style().unpolish()/polish()`，QSS 以 `QFrame[state="hi"]` 選取 |
| 格線版面 | `QGridLayout`／`QHBoxLayout`／`QVBoxLayout`；探頭欄數依定義檔動態建立 |
| 刻度條 | 自訂 `QWidget`，覆寫 `paintEvent` 以 `QPainter` 依 5.6 公式繪製 |
| SVG 圖示 | `QSvgRenderer` 或 `QIcon`；繪製前將 `currentColor` 替換為狀態色 |
| 透明度淡化 | `QGraphicsOpacityEffect`（0.55） |
| 閃爍、旋轉、倒數 | `QTimer`；旋轉可用 `QPropertyAnimation` 或於 `paintEvent` 中旋轉 |
| 對話框 | `QDialog`（模態）；日期用 `QDateEdit`；儲存位置用 `QFileDialog.getSaveFileName` |
| 編輯 BOOTP 設備 | `QDialog` + `QStackedWidget` 切換三個步驟；偵測表用 `QTableWidget`；DL-EN1 卡片放在 `QScrollArea` 內，依草稿資料動態建立；MAC 下拉建議用 `QCompleter`；上傳用 `QFileDialog.getOpenFileName` |
| 動態排版 | 定義檔套用後清除並重建排與探頭元件，不需重啟程式 |
| 提示訊息 | 無邊框 `QLabel` 浮層 + `QPropertyAnimation` 控制透明度 |
| 字型 | 啟動時以 `QFontDatabase.addApplicationFont()` 載入 Barlow Semi Condensed；確認系統有 Noto Sans CJK TC |
| 全螢幕 | `showFullScreen()` |

也可選擇以 `QWebEngineView` 直接載入 HTML 原型，由 Python 透過 `QWebChannel` 推送資料；兩種做法皆須符合本規格的外觀與行為。
