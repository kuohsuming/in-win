# 表面平整檢查 作業員畫面設計規格

本文件把畫面原型（`board-station.html`，與本文件一起提供）的版面、顏色、字型、元件與狀態轉成文字，供開發實作。畫面上的排與探頭完全依 DL-EN1 定義檔（`dl-en1.json`）動態產生，相關規則見需求規格書 3.7、3.8。數值以原型為準；原型中最上方的「樣本畫面」切換列只供展示，正式版不實作。

---

## 1. 目標裝置與設計原則

| 項目 | 規格 |
| --- | --- |
| 解析度 | 1920 × 1080，全螢幕（無視窗標題列） |
| 觀看距離 | 作業員站立，距螢幕 1～2 公尺 |
| 語系 | 繁體中文；字型必須離線可用（不可依賴網路字型） |
| 操作 | 觸控或滑鼠；作業員只使用「重讀」「下一片」兩顆大按鍵 |

設計原則：

1. **結果優先**：結果橫幅是全畫面最醒目的元素，一眼即可判斷能否放行。
2. **不只靠顏色**：合格、偏高、偏低、異常各有不同形狀的圖示與文字，色弱也能分辨。
3. **非合格一律紅色並標 FAIL**：超出規格與設備異常都用紅色，以文字與圖示區分原因。
4. **錯誤點最醒目**：不合格時，問題點加粗紅框，合格點淡化。
5. **不可誤導**：資料不完整或設備異常時絕不顯示綠色合格。

## 3. 字型

| 代號 | 字型堆疊 | 用途 |
| --- | --- | --- |
| 文字字型 | Noto Sans TC → Noto Sans CJK TC → PingFang TC → Microsoft JhengHei → sans-serif | 所有中文與一般文字 |
| 數字字型 | Barlow Semi Condensed → 文字字型 | 編號、時間、測量值、標準值、允收範圍、倒數秒數 |

- Ubuntu 上以 `fonts-noto-cjk` 提供 Noto Sans CJK TC；Barlow Semi Condensed（SIL OFL）隨 App 附帶字型檔，以 `QFontDatabase.addApplicationFont()` 載入。
- 所有數字使用**等寬數字**（tabular figures），數值變動時不跳動。
- 字重：400 一般、500 中等、700 粗、900 特粗（結果大字、排名稱、狀態徽章）。

**淡化規則**：整片判定為不合格或設備異常時，所有「合格」方塊透明度降為 55%，讓問題點最醒目。

### 5.6 刻度條

高 34px，以百分比定位：

| 部位 | 規格 |
| --- | --- |
| 底線 | 全寬，距頂 14px，高 6px，`line`，圓角 3px |
| 允收區間 | 左 20%～右 80%（佔中間 60%），距頂 10px，高 14px，`go` 透明度 35%，圓角 2px |
| 標準值線 | 50% 位置，距頂 7px，寬 2px、高 20px，`ink-2` |
| 測量值指標 | 向下三角形，寬 18px、高 13px，尖端朝下，顏色同測量值 |

指標水平位置：

```
區間寬 = (上限 − 下限) ÷ 0.6
起點   = 下限 − 區間寬 × 0.2
位置%  = (測量值 − 起點) ÷ 區間寬 × 100，限制在 2%～98%
```

註：標準值線固定畫在 50%，標準值不在上下限正中央時與實際位置略有偏差，原型即如此處理。

### 5.10 編輯 BOOTP 設備對話框

由頂端工具列的鉛筆按鍵開啟，用來檢視網路上送出 BOOTP 請求的設備、決定每台的設備類型，並編輯 DL-EN1 設定；設備與其 MAC 一律來自 BOOTP 偵測，不可手動新增或修改 MAC。對話框分三個步驟：密碼 → 編輯（清單 ＋ 內容兩欄式）→ 確認套用。

**容器**

檢查規則：協同合作設備 只檢查 IPv4（格式、網段、不可為 .0／.255 或量測 PC 的 IP、與其他設備不重複）；以下適用 DL-EN1 使用中、停用——至少 1 台、最多 8 台「DL-EN1 使用中」；key 為小寫英數與連字號 1～30 字、不可以連字號開頭；name 1～10 字；IPv4 格式正確、在設備網段、非 .0／.255、不同於量測 PC；Port 空白或 1～65535；最多探頭數 1～15；至少 1 個探頭且不超過最多探頭數；探頭 ID 為 1～最多探頭數且同台不重複；位置名稱 1～10 字；key、name 在所有 DL-EN1 間不可重複；IPv4 在所有配發 IP 的設備（DL-EN1 與協同合作設備）間不可重複。

**定義檔配合調整**：`dl_en1` 每台增加 `enabled`（布林，預設 true）；新增頂層 `other_devices` 陣列，每筆 `{ "mac": "…", "type": "cooperative", "ipv4": "…" }`。BOOTP 對應檔產生 `dl_en1`（含停用）與 `other_devices` 中所有設備的 MAC 與 IP 對應。

**步驟三：確認儲存（按「儲存」後）**

| 部位 | 規格 |
| --- | --- |
| 變更清單 | 每項一個區塊（背景 `panel-2`，邊框 1px `line`，圓角 6px，內距 10px 14px，15px，行高 1.6）；開頭標示「新增」（`go`）、「變更」（`ink`）、「移除」（`ng`）、「標記」、「順序」；使用中與停用的切換也以紅底紅字標示；MAC 與 IP 的變更以紅底紅字粗體標示 |
| 變更比對 | 以 key 對應新舊 DL-EN1；比對使用中／停用、排名稱、IP、Port、最多探頭數、探頭新增／移除／改名、主畫面排列順序；協同合作設備 以 MAC 對應，比對新增、移除與 IP 變更 |
| 影響區塊 | 紅框紅底：「需將下列設備重新上電才會取得新 IP」（新增者與 IP 變更者，含協同合作設備）、「下列探頭尚未設定允收標準，量測時將顯示設備異常」、「下列量測點將從畫面移除」 |
| 按鍵 | 「返回修改」、「確認儲存」（無任何變更時停用） |

**儲存後**：關閉對話框 → 寫入定義檔並產生 BOOTP 對應、重啟 dnsmasq（正式版，失敗時自動還原）→ 清除目前編號與重讀次數 → 依新定義重建主畫面 → 自動執行偵測設備；提示訊息「已儲存定義檔並更新 BOOTP 對應；請將 後排、設備 4 重新上電」。

## 9. PySide6 實作對照

| 原型做法 | PySide6 做法 |
| --- | --- |
| CSS 色票變數 | 於 Python 定義色票表，產生 QSS 字串；深淺主題各一份 |
| `class="probe hi"` 等狀態 | `setProperty("state", "hi")` 後 `style().unpolish()/polish()`，QSS 以 `QFrame[state="hi"]` 選取 |

| 刻度條 | 自訂 `QWidget`，覆寫 `paintEvent` 以 `QPainter` 依 5.6 公式繪製 |
| SVG 圖示 | `QSvgRenderer` 或 `QIcon`；繪製前將 `currentColor` 替換為狀態色 |
| 透明度淡化 | `QGraphicsOpacityEffect`（0.55） |
| 閃爍、旋轉、倒數 | `QTimer`；旋轉可用 `QPropertyAnimation` 或於 `paintEvent` 中旋轉 |
| 對話框 | `QDialog`（模態）；日期用 `QDateEdit`；儲存位置用 `QFileDialog.getSaveFileName` |
| 編輯 BOOTP 設備 | `QDialog` + `QStackedWidget` 切換三個步驟；左右兩欄用 `QSplitter` 或 `QHBoxLayout`；DL-EN1 清單用 `QTableWidget`（整列選取）；內容用 `QFormLayout`；最多探頭數用 `QSpinBox`；探頭表用可編輯的 `QTableWidget`；檢查訊息用 `QListWidget`；上傳用 `QFileDialog.getOpenFileName` |

| 全螢幕 | `showFullScreen()` |
